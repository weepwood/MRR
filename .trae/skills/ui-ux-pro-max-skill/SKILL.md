## How Design System Generation Works

1. **Analysis**: The AI analyzes your project requirements, target audience, and brand identity
2. **Pattern Selection**: Recommends optimal page structure patterns based on your goals
3. **Style Matching**: Generates a cohesive visual style that aligns with your brand
4. **Color Palette**: Creates a harmonious color scheme with accessibility considerations
5. **Typography**: Selects font pairings that enhance readability and brand personality
6. **Effects**: Recommends subtle animations and interactions that improve user experience
7. **Best Practices**: Provides guidelines to avoid common design pitfalls

## Key Features

- **Design System Generation**: Creates complete, tailored design systems in seconds
- **Cross-Platform Support**: Works with multiple frameworks and platforms
- **Accessibility Focus**: Ensures WCAG AA compliance
- **Performance Optimization**: Recommends lightweight design solutions
- **Responsive Design**: Provides breakpoints for all device sizes
- **Best Practices**: Includes comprehensive design guidelines

## Usage Guidelines

Invoke this skill when:
- You need to create a new design system for a project
- You want to improve an existing UI/UX
- You need design recommendations for specific components
- You want to ensure accessibility and performance in your designs
- You need guidance on typography, color, or interaction design

## Supported Platforms

- Web (React, Vue, Angular, etc.)
- Mobile (iOS, Android)
- Desktop applications
- Design tools (Figma, Sketch, etc.)

## Performance and Accessibility

- **Performance**: Excellent - optimized for fast loading and rendering
- **Accessibility**: WCAG AA compliant - ensures inclusive design
- **Responsiveness**: Fully responsive - works on all device sizes

## Anti-patterns to Avoid

- Bright neon colors
- Harsh animations
- Dark mode for inappropriate use cases
- AI purple/pink gradients
- Emojis as icons (use SVG instead)
- Lack of hover states
- Poor text contrast
- Missing focus states
- Ignoring prefers-reduced-motion
- Incomplete responsive design

## Pre-delivery Checklist

- [ ] No emojis as icons (use SVG: Heroicons/Lucide)
- [ ] cursor-pointer on all clickable elements
- [ ] Hover states with smooth transitions (150-300ms)
- [ ] Light mode: text contrast 4.5:1 minimum
- [ ] Focus states visible for keyboard nav
- [ ] prefers-reduced-motion respected
- [ ] Responsive: 375px, 768px, 1024px, 1440px
