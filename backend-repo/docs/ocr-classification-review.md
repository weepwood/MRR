# 分类规则与人工审核（阶段三）

关联 #342、#91。P1。规则分数不是正确概率；本阶段只保存建议和人工审核，不自动归类。

## 行为

规则与词库作为配套版本维护，草稿可编辑；发布在事务中归档旧版本并发布新版本。
运行任务固定使用创建时的版本。恢复旧版会复制成新草稿，不修改已发布版本。
规则最多 1000 条，词库最多 1000 条；正则由 RE2/J 执行，不支持回溯/反向引用。
标题取页面顶部 25% 内不超过 64 字符的独立文字行；正文提及标题不能触发标题规则。
纠错只作用于派生文本，不能进入自动路径；明确别名可以匹配独占标题。
无匹配保持未分类，不能默认写入“其它”。冲突、弱置信度及仅正文匹配交人工审核。

OCR 事实先独立提交，分类失败不会丢弃成功文字；分类仍保留 PROCESSING 检查点，
崩溃恢复可以复用已提交文字。规则失败的页面保留 CLASSIFICATION_FAILED 状态供重试。

## 类型变更与审核

既有图片改类接口和通用扫描更新都通过 ImageTypeService；操作者来自 AuthContext
并重新读取账号权限，类型与审计原子提交。type_version 在所有数据库类型改变时递增，
人工重复确认同一类型也递增，以阻止旧建议或后续回退覆盖人工操作。
审核重新读取源哈希；源文件、OCR 版本、当前类型或类型版本发生变化时拒绝旧建议。
原图核对通过现有带认证的内容网关获取 Blob；不暴露源地址或凭据。
审核授权与任务所有权分离：具有病案读取和审核权限的人员可以审核建议。
规则测试只接受已有影像 ID，不接收任意文件路径；OCR/分类请求正文不进入访问日志。

## 验证

2026-10-18：40 项相关后端单元测试及 8 项 PostgreSQL 16 集成测试通过。
包括类型 0/11/15、规则冲突、正文误命中、纠错降级、安全正则、审计失败回滚、
大整数真实用户 ID、人工改类后恢复 0 仍拒绝旧建议、重复审核拒绝及 OCR 事实保留。
相关测试先复现失败再修复。前端类型检查通过。

## 回退

关闭 OCR 后可回退应用，保留新增版本和审计；已发布规则通过复制旧版并重新发布恢复。
自动应用本阶段未开放。真实病案样本、生产性能与独立审查仍为上线前置条件。
