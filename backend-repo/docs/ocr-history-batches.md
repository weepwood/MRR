# 历史未分类 OCR 批次（阶段四）

关联 #342、#417。P1。自动应用边界见 [自动归类](ocr-auto-apply.md)。

## 逐案处理（2026-10-25）

新批次按有效上架号处理：sjh 非空用 sjh，否则用 bah，只去首尾空格、保留前导零。
回退值不回写编号或用于重建存储路径。执行绑定已核验 archive_id；有效编号对应多个主档时暂停，
提示 CASE_CODE_CONFLICT，不猜测合并。旧批次 case_mode=false 仍按原游标模式运行。

新批次每轮登记完整病案的未分类页面，固定 pages/id 顺序。全局历史任务逐案进行，当前病案暂停时
保留位置；手动任务仍优先。完成指 OCR、第二遍上下文分析、自动应用结束或降级审核；人工审核可随后处理。
同案超过10000页提示 CASE_TOO_LARGE；额度不足提示 CASE_EXCEEDS_BUDGET；ID上下界截断同案的未分类
页面提示 CASE_RANGE_INCOMPLETE。取消后调整范围/额度新建批次；编号冲突修正后可以续跑。
预览是有限候选上限及首案检查，不声称全库精确数量。游标与整案登记同一事务，交错扫描ID不会漏案。

第二遍每次只读取一页与最多两张前页OCR，已分类页/重复页码/缺页可作为阻断边界。
续页必须自身含续页、续表或接上页标识，并有兼容尺寸；只从独立明确标题参考最多两页。
正反面候选还需显式背面/反面标识，不按奇偶强配。当前规则保守，不能认定实际扫描都有这些标识。
上下文结果始终 autoEligible=false，页面展示依据与参考页，并通过受保护内容接口并排查看。
人工确认类型或确认关系时检查当前与参考页的源哈希、OCR/类型版本、归属和页序；发生变化须重新生成建议。
解除待审核的正反面关系会同时拒绝其分类建议；已确认正式类型不随解除关系自动回退。
关系动作追加真实操作者审计，原始图片与OCR不合并。关闭自动应用后未处理自动候选降为人工审核。

新增 cases 读取接口保留旧 jobs 接口；items 的 after 仍传上次返回的最后一个 scanId，服务端按固定页序定位。
结构和有效编号索引通过新增迁移演进；不修改历史迁移，不回填三千万影像表。
详细取舍、恢复与限制见 ADR-0007 和 docs/engineering/ocr-case-sequence-proposal.md。

## 范围与运行条件

管理页“历史影像识别”先预览起止 ID 和最多页数，再创建固定上界的有限批次。
预览最多读取 maxPages+1 条候选，显示本次范围内的上限，不声称全库精确数量。
只选择有效、btype=0、archive_id 存在且编号与主档一致的页面；异常用 ocr-preflight.sql 隔离统计。
每批最多 10000 页，最多 10 个活动/暂停批次；旧模式每次最多登记 200 页，队列最多 100 个活动病案任务。
上一游标段的任务完成后才登记下一段，同病案唯一活动约束继续生效。
游标与所有子任务/页面登记在同一 PostgreSQL 事务中提交；失败回滚整个游标段。

默认窗口为 Asia/Shanghai 22:00–06:00。先以关闭 OCR 的状态测量正常调阅 P95，配置：

```properties
ocr.runtime.image-p95-baseline-millis=实际测得的毫秒值
```

这不是可直接粘贴的数值。已有 HTTP timer 增加影像路由 P95；无基线、无测量、
CPU 连续 5 分钟超过 70%、可用内存不足 20% 或 P95 恶化超过 10% 时停止历史领取。
无影像流量导致测量窗口过期时保持等待；不得通过伪造基线绕过。
单病案手动任务不受历史窗口限制，并且优先领取。

## 暂停、取消与权限

暂停在当前页完成后停止领取历史页，不影响手动任务；续跑从持久化检查点恢复。
取消会取消已登记子任务，取消处理不受夜间/资源门槛限制；已成功文字保留。
ocr:batch-run、ocr:run 和 record:read 必须同时具备。创建人或管理员可以管理批次。
批次授权使用真实账号 ID；后台重新检查账号/权限，撤权后暂停或取消后续执行。

## 数据库与回退

新增批次结构及两个未分类候选部分索引；索引独立非事务并发建立。
索引失败时先检查 pg_index.indisvalid 与 Flyway 失败记录，再按运维流程修复后重跑；
不得修改已有 main 迁移。新索引迁移在重试时会重新构建该迁移拥有的索引。
三千万级副本上仍须执行 EXPLAIN (ANALYZE, BUFFERS)、评估磁盘与构建时间。
关闭 OCR，取消或暂停批次后可以回退应用；保留任务、文字与索引，不直接删除数据。

## 本地验证

2026-10-18：相关单元测试和 PostgreSQL 16 的 11 项 OCR/分类/批次集成测试通过。
批次测试覆盖 200 页游标段、201 页总上限、重复调度不重复登记、暂停后无法领取、
取消绕过资源门槛，以及子任务登记失败时游标和任务均回滚。前端类型检查通过。
目标 Windows Server、实际存储和生产规模性能尚待验收，默认不开启历史处理。
