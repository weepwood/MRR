# ADR-0005：核心数据交换中心与三千万级大表分批策略

- 状态：Accepted
- 日期：2026-10-09（补录；实现随 v0.6.5–v0.7.x 合入 `main`）
- 决策者：MRR Team
- 关联 Issue：待补
- 关联 PR：待补
- 替代 ADR：无

## 背景

患者、统计、档案装箱与扫描记录需要模板下载、文件校验、导入与条件导出，且要从 Nginx 原图批量迁移到 OSS。核心业务表 `mr_scan` 预计约三千万行，任何"全表扫描 + 单事务"的导入导出都会锁表、拖垮线上。此前缺乏统一的导入导出与分批策略，风险集中在数据完整性与可用性。

约束：

- 大表查询禁止无界扫描、全量加载、未评估的大事务（AGENTS.md 数据库规则）；
- 批处理必须可分批、可重试、可观察，避免单事务长期占锁；
- 数据修复/导入必须先有只读统计、分批、重试、审计与恢复策略；
- 导入定位键必须利用索引，避免每条记录扫描整个目录。

## 决策

建立**核心数据交换中心**与配套大表策略：

- 数据交换：患者/统计/档案装箱/扫描记录的模板下载、文件校验、导入与条件导出（`DataExchangeController`、CoreDataExchange 服务）；
- 导入定位键使用 `(folder, filename)` 复合索引（`V20260723011000`），**CONCURRENTLY** 构建以避免阻塞线上 DML，并先 `DROP ... CONCURRENTLY IF EXISTS` 清理上次中断留下的 INVALID 索引；
- 异步导出：`archive_export_job` 表记录状态、所有者（`owner_user_id`）、`download_count`、`last_downloaded_at`，支持进度、取消、重新下载、临时文件过期与 Range 续传；
- OSS 迁移管理：按上架号（sjh）分组、上架号缺失等待补齐、失败重试、校验和、任务统计（`V20260722110000`）；
- 患者分析/数据质量：身份证缺失、疑似同人、年度病案与科室分布。

## 必须保持的不变量

- `mr_scan` 导入/导出/迁移不得无界扫描或单大事务占锁；
- 批量操作必须可分批、可重试、可观察、可回滚；
- 导出任务必须受权限、配额、过期、取消、Range 与临时文件清理约束；
- 前端不得无界加载整份大病案。

## 方案边界

### 包含

- 模板下载、文件校验、条件导入/导出；
- 基于索引的分批导入定位；
- 异步导出作业生命周期与配额；
- OSS 迁移的分组、重试与校验。

### 不包含

- 前端直接拼接受保护影像源 URL（仍走统一内容网关）；
- 改变 `mr_scan` 既有业务语义的批量改写；
- 跨机构数据同步（非本阶段范围）。

## 替代方案

### 方案 A：导入时按 bah 全表定位

- 优点：实现直接。
- 缺点：三千万行无索引扫描，线上阻塞。
- 未采用原因：违反大表无界扫描禁令。

### 方案 B：导出在请求线程内同步打包整案

- 优点：简单。
- 缺点：大请求超时、内存溢出、无取消/续传。
- 未采用原因：违反异步、配额、Range 续传与临时文件清理要求。

## 影响

### 正面影响

- 导入导出与 OSS 迁移首次具备可分批、可重试、可审计的工程化能力；
- 索引策略避免线上锁表。

### 负面影响与技术债

- 数据交换校验/导入逻辑复杂度高，需持续测试覆盖；
- 导出临时文件清理依赖调度，需监控残留。

### 安全、隐私与审计

- 导入文件含患者信息，校验与落盘需防路径穿越与敏感信息泄露；
- 导出受 `record:download`/`record:pdf:export` 权限约束，所有者隔离。

### 数据库、性能与容量

- `idx_mr_scan_folder_filename` 为三千万级复合索引，CONCURRENTLY 构建；
- `archive_export_job` 增加下载统计列与状态索引；
- OSS 迁移日志表随迁移量增长。

### Chrome 86、Windows 与部署兼容性

- 纯后端能力，前端仅展示进度；不影响兼容。

## 迁移方案

- 数据库：`V20260721193000`（image sources + export jobs）、`V20260721224000`（export job owner）、`V20260722110000`（oss migration management）、`V20260723011000`（folder+filename 索引）、`V20260721122000`（medical record code match key）；
- 代码：数据交换服务、导出作业服务、OSS 迁移管理；
- 配置：导出配额/临时文件过期由 `ArchiveExportProperties` 等控制；
- 文档：用户手册补充数据交换与 OSS 迁移说明。

## 回滚与前向修复

- 上述迁移已合入 `main`，**不得回写**；
- 功能回滚通过关闭入口或配置开关，数据表保留；
- 导入失败以分批重试 + 审计恢复，不整表回滚；
- 导出临时文件由清理任务兜底。

## 验证

- PostgreSQL 集成测试：`CoreDataExchangePostgresqlIT`、`MedicalRecordImportBoundaryPostgresqlIT`、`StatisticsImportRollbackPostgresqlIT`、`OssMigrationManagementMapperPostgresqlIT`、`ScanMapperPostgresqlIT`；
- 单元测试：导出作业校验/所有权/策略测试、DataExchange 控制器测试；
- 性能与容量：三千万级导入的定位索引命中与并发构建不阻塞验证；
- 生产或灰度验证：在隔离环境完成真实导入/导出/OSS 迁移验证。
