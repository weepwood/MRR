# 第十批候选运维边界与回滚（非正式部署指南）
P1实验候选：普通内存审计仍默认，mrr.audit.spool.enabled、grouped、mrr.audit.admission.enabled均不自动开启。正式采用需独立审查、受保护Windows/NTFS与现场负载，不得将本文件直接当作上线授权。
## 独立前置医疗事件
app.medical_audit_event独立账本；event_id为随机UUID关联ID加I/O后缀，原HTTP request_id为关联字段非该表唯一主键。INTENT表示业务调用前持久化准入，OUTCOME表示观察到的HTTP状态与异常信号，不证明业务事务成功或客户端收到全部内容。无OUTCOME是未知，不重执行业务、不伪造成功。前置gate在既有认证/授权/降级拦截器之后，按明确内部handler集合执行；资源级授权仍由业务处理器执行，因此被业务拒绝的请求也可能有合法INTENT+403 OUTCOME。公开外部调阅/票据接口未纳入，保持专用审计原事务。事件仅稳定内部actor ID、模板、方法、HMAC保护的URI+query范围、请求关联、时间及观察状态，不保存请求体；请求体资源范围、实际患者/影像归属及外部用户身份仍待细粒度扩展，不能代替完整医疗审计。
预留每条4KiB、两个事件的逻辑记录/字节预算，未预分配物理磁盘；持久化失败拒绝新请求503，已有OUTCOME发布失败保留预留并锁止新准入，重复Servlet回调不会生成不同的同ID结果。进程重启释放易失预留但已持久化INTENT保留，未知结果需人工审查。真实数据库排他锁导致队列满而拒绝影像，释放后恢复。不能承诺硬墙钟I/O截止、所有异步断开路径、掉电、进程停止中完整OUTCOME。无生产密钥、患者或正式存储参与。事件表的访问角色、归档/保留期、未配对事件告警及受控查询界面需要独立治理；不开放通用数据库浏览。
## v3密钥代次
两个域分别使用MRR_AUDIT_SPOOL_KEY、MRR_MEDICAL_AUDIT_KEY；配置KEY_RING和ACTIVE_KEY_ID（按各域前缀），最多8代，id仅1–32字符ASCII字母数字下划线连字符，AES-256-GCM随机nonce，版本/文件名/id绑定AAD。原v1/v2读取仍需原legacy key。跨域已配置legacy及ring密钥不得相同；不得复用JWT或审计HMAC，后两者独立性由运营配置核对，禁止把密钥提交、导出或打印。当前轮换需停服务：在保留旧钥及所有未确认段的前提下，增新id并指定active，重启，读旧写新；逐ID核对已入库并确认没有该代待确认或隔离段后，才能按合规流程退役旧钥。禁止直接改现存id的key。新格式不能被第九批旧二进制读取，降级前必须停止新增、逐ID排空，并依法处置所有held段，保留密文及钥匙备份；不得为回滚删除未知记录。
## 段隔离及重放
普通审计候选仅在确定身份冲突后回滚并逐完整段重试，确定冲突段原子重命名为.held并同步目录；配置max-replay-age-days>0时整段中任意记录超过阈值也保留为.held。0默认关闭年龄策略，不推定医院留存天数。未知网络/事务故障不自动隔离。启动检查文件属性、AEAD完整性与所有密钥；held段保留密文、验证和预算，不纳入正常投递；损坏/未知key-id/不合法文件仍阻止启动。不提供自动释放、删除或医疗明文导出。隔离状态是受信服务账号目录内文件名标志（不是独立签名检查点），仅通过运维审查且服务停止后按受控流程恢复，必须保留旧密钥和原证据、独立核对事件身份与保留期。没有持久幂等凭证覆盖已清理DB数据，不能声称过期隔离等同防重放证明。活动WAL、独立检查点及磁盘断电恢复未实现。
## 迁移对象副作用与回滚
新增nullable migration_claim_id，不设表全量默认；上线前检查DDL锁预算/旧实例兼容，停止旧迁移工作者，不能混用旧写者。领取比较来源快照和尝试次数并生成UUID；完成比较当前UUID和来源快照，失败/重试按当前UUID条件写入，旧工作者不能覆盖新代次。完成冲突释放仍属当前UUID的领取至重试等待，保存对象不签发；单实例启动恢复原有方式保留，多实例启动不能证明不会中断另一实例领取。当前同代次失败更新仅UUID/有效状态，若来源已变更仍需后续来源快照约束。实际本地对象写入后模拟ACK丢失，重试校验文件MD5而非重复上传。未证明实际S3/OSS条件创建、同名对象并发覆盖或真实DB迁移提交ACK丢失恢复；禁止自动孤儿删除。后续先只读盘点对象key哈希/大小/MD5、当前有效引用、活动claim和保留期；存在疑问、旧客户端、部分引用或失败确认时保留，必须经业务负责人独立复核后才允许运营清理。回滚停止迁移与审计准入，排空逐ID，保留前向表和列；不改历史Flyway、不执行逆向删除。
## Windows与物理I/O
本机为macOS外接共享APFS存储，候选强制POSIX真实私有目录/0600文件/0700目录。Windows服务账户DACL、继承ACL/重解析点、NTFS目录同步及真实掉电均未验证，不绕过检查。已读取系统块设备累计写入计数但未能将驱动器统计唯一归因至本次共享设备实验；不报物理写入量或SSD磨损结论。后续使用专用隔离卷和已核对设备计数，区分读写/其他进程/文件系统缓存，记录起止计数和可比工作量。程序逻辑密文字节、force计数仅反映应用发布成本。
