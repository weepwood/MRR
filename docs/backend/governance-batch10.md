## 2. 持久引擎、隔离及密钥
- v3可选key-id帧：AES-GCM绑定版本/文件名/key-id，最多8代，显式active写入，旧key读取，兼容v1/v2原key；两个域均支持配置ring，重启式轮换而非热轮换。未知key-id/错误key/损坏严格拒绝启动。单测真实旧钥缺失拒绝、旧新同时读、确认旧段后退役旧钥。独立域检查含legacy/ring；JWT及HMAC分离仍靠安全运营配置核对。
- 普通审计确定身份冲突回滚后按完整段隔离；显式年龄策略0默认关闭、配置后超过阈值整段hold；不推定医院保留期。原子重命名.held及目录force，继续计入容量，启动检查AEAD，非确定网络故障保留待投递。真实PG冲突/9天旧记录（显式7天实验策略）均hold，健康段正常入库，既有DB未改、重启仍保留两段；未自动丢弃。旧二进制不支持v3/held，降级需逐ID排空和合法处置所有隔离段。隔离标志是私有目录文件名，不是独立认证检查点。损坏段仍阻止启动，不自动跳过。
