# UI 组件展示页

入口为登录后的「帮助 → UI 组件」，地址 `/ui-components`。用途是设计验收：操作项目现有组件，查看真实状态、明暗主题和响应式表现。它是常用组件目录，不是所有组件的完整 API 文档。

## 范围与使用

9 组示例覆盖 31 个组件与样式入口：

- 基础与导航：按钮、按钮组、页签、提示和快捷键样式。
- 表单与选择：文本、说明、下拉、日期、数量、复选框、开关和滑块。
- 数据与组合：指标卡、筛选栏、表格、状态标签、行操作和分页。
- 反馈与浮层：正常、加载、空态、错误重试、进度、对话框、抽屉和气泡。
- 设计令牌：颜色、圆角，以及页面本身使用的页头与页面壳。

左侧分类与组件名搜索可以组合使用；无匹配时可恢复全部示例。「重置所有示例」清除搜索/分类并恢复本页交互状态。切换分类或离页后不会保留已打开的示例浮层。

主题跟随现有全站外观设置，可使用右上角「应用外观设置」切换；该入口原有的保存与同步语义不改变。展示页没有单独的主题引擎或外观持久化，也不自动改写全站配置。日期、编号、指标和表格均为合成数据，示例操作仅更新本页内存。
