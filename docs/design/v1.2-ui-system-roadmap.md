## 事实与边界

- 既有设计语言、明暗及暖色主题、共享页面壳和组件展厅保留。历史 Fa/reka 控件处于逐类迁移期。前期双族视觉对照仅过渡；用户进一步明确同类只保留一种实现，现以Element Plus为唯一目标，按[控件唯一实现与源码使用清单](component-ownership.md)迁移，不新增重复Fa控件或第三套主题。
- 基线 src/views 下 96 个 Vue 文件。按源码精确开始标签计数（含模板中示例/分支/嵌套；不等于运行次数、页面或缺陷数量）：el-input 136处/34文件、el-input-number 22/11、el-select 50/29、el-dialog 19/13、el-drawer 2/2、el-table 58/32、MrrDataTablePanel 13/12、MrrFilterBar 9/9、AppEmpty 42/27、AppError 31/23、el-empty 0。原生表格可以是组合组件内合理用法，需沿调用关系核实，不能仅凭数字判定违规。
- 现有 gallery 12组示例、已有按钮双族对照与状态、实际 E2E；目录未索引 ElButton，表单缺原生文本/只读/错误对照，作为首批明确差距。不复制既有按钮样式或重复实现已通过的验收。
- 全站窄屏必须核对实际可用容器宽度而非仅视口；侧栏、详情卡与工具区叠加导致拥挤的场景需单独验收。不能用全局 overflow:hidden 隐藏缺陷。
- 禁止调整真实业务、数据、权限、API、身份、审计、分页、提交语义或生产部署来取得视觉一致。禁止将合成示例作为生产数据，正式 main、V1.1 保持冻结。

## 实施顺序

下表的 P0/P1/P2 是开发优先级，不是 AGENTS 工程风险等级。共享控件变更一般 P2，权限/保存/发布等按原规则升为 P1/P0。

| 优先级/批次 | 范围 | 实际交付和验收 |
|---|---|---|
| P0 / 01 | 令牌与 CSS 所有权 | 盘点 tokens.css、themes、form-controls.css、element-plus-overrides.css、UnoCSS 与页面局部规则；同一角色一份数值来源；按计算样式识别覆盖冲突，记录例外；复用令牌/对比度/兼容测试 |
| P0 / 02 | 按钮、文本、数字、搜索、选择、开关、复选、单选、分段、日期 | 按唯一实现迁移并建立视觉/交互契约；正常、悬停、按下、焦点、禁用、加载、只读、错误和尺寸矩阵；比较真实控件尺寸、焦点和键盘；避免盲目机械封装 |
| P0 / 03 | 表单与验证 | 统一标签关联、帮助/错误、必填、长文字、组合布局、数值边界；保留提交与清空语义、错误恢复、防重复提交、可访问描述；禁用与只读区分 |
| P1 / 04 | 数据与反馈组件 | 表格、分页、筛选、行操作、指标、状态、首次加载/刷新/空/错误、工具栏；按查询/详情/统计模板复用，区分计数与服务端总数 |
| P1 / 05 | 浮层与全局导航 | 菜单、弹窗、抽屉、提示、层级、焦点回归；统一壳层/侧栏/页头/滚动、窄屏实际可用宽度；保留不适合普通壳的独立页 |
| P1 / 06 | 页面族迁移 | 先日志/审计/记录/患者与设置，再统计/数据治理/运维与影像；按相关组件族集中 PR，避免每页一小 PR；不机械替换合理例外 |
| P2 / 07 | 展厅与集中视觉验收 | 现有 /ui-components 持续扩展实际组件、状态、属性及使用说明；双主题/暖色、长内容、移动/桌面、键盘、动效开关；截图与计算样式证明，按风险最终复验 |

每批闭环：当前事实与目标 → 组件/调用方影响和回滚 → 失败证据 → 公共修复 → 相关真实页面迁移 → 定向单测/浏览器与截图 → 更新规范/目录 → CI/自审/集成 → 独立预览。共享 CSS 不允许通过无关页面 !important 覆盖“修好”单一截图；例外必须有理由和验证。无需每轮重建完整 V1.1 制品。
