2. Repository 使用条件更新并返回受影响行数；Service 检查领取及完成结果，避免未领取任务写文件或覆盖终态。
3. 临时文件删除返回明确结果；失败保留路径及状态，后续清理重试。进度按批次或时间更新，异常仅返回安全固定提示。
4. 执行相关单元、PG16 集成、权限及治理检查，再由独立上下文读取 Issue、diff、测试和架构进行审查。

不变项：接口及响应字段、权限和审计、Flyway、部署与配置格式均不变；不接触医疗原文件。
不处理请求阶段完整准备优化、旧前端下载代码移除、孤儿文件目录对账和真实存储验收，继续由 #171/#350 跟踪。

## 验收与回滚

- 终态不会被开始、成功、失败或取消操作覆盖；终态过期清理仍可进入 EXPIRED。
- 已提交取消请求的 PROCESSING 任务不能成功；取消/完成并发按数据库条件更新线性化。
- 删除失败不能清空路径或标记过期；修复文件占用后可由下一轮清理完成。
- 失败清理通过现有 updated_at 轮转到批次末尾；200个持续失败任务不能阻塞后续可清理文件。失败累计由现有Micrometer指标 `mrr.archive.export.cleanup.failures` 暴露。
- Worker沿用现有requestId MDC，以任务UUID关联安全日志，并恢复原MDC；不展开日志参数或异常正文。完成提交确认丢失时保留已成功输出，数据库不可用时保留文件供重启恢复。
- 未授权账号及非所有者仍被拒绝；客户端错误不含路径、凭据或底层异常。
- 不新增表或迁移。可独立撤销本 PR 代码并重新构建当前兼容基线；不得回退到旧的令牌撤销或隐私实现。
- 回退后恢复旧竞态风险，维护期间应暂停创建导出，等待活动任务结束后替换应用；已有成功文件和任务不删除。

真实 Nginx/NAS/OSS、Chrome 86、医院容量与数据库副本的验证尚待 #350，不以本机测试替代。
