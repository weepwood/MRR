# 医院副本验收记录模板

复制到院内受控目录填写，禁止将填写后的记录、路径、患者信息或备份提交Git/Issue/Artifact。
执行说明：[医院副本验收包](hospital-replica-acceptance.md)。关联 #350。

## 基线

- 验收编号、时间、执行人、复核人：待填写
- VERSION / Git SHA / 发布包SHA256 / Flyway上限：待填写
- Windows Server / PostgreSQL / Nginx / Chrome版本：待填写
- 副本授权与隔离确认、数据时间点与规模、存储来源覆盖：待填写
- 性能、容量、RPO/RTO目标与现场批准人：待填写
- 证据保管人与院内保管位置：仅院内填写
