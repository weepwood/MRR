# OSS 迁移页轮询职责拆分

关联 #362；风险 P2。页面原先同时维护表单、列表和两个 setInterval，异步请求超过轮询间隔会产生重叠，已退出页面或任务切换后旧响应仍可能覆盖新状态。

本批仅将定时器生命周期与轮询规则移至页面内的 `composables/useMigrationPolling.ts`。沿用现有 API 模块、权限、任务状态和通知，不建立第二套 Store、请求机制或通用任务平台。页面负责业务加载和展示，composable 负责每两秒查询任务、每十五秒刷新概览、停止与清理。

任务和自动概览各自限制为一个正在执行的轮询请求；任务失败停止轮询，显式重启可恢复；任务结束刷新一次。任务切换、停止/重启或组件销毁后忽略旧任务结果，Vue scope 销毁时清理两个定时器。概览刷新失败允许下一轮恢复。

该限制只覆盖定时轮询，不强行串行化用户手动刷新。已经交给页面执行的概览刷新或终态后的完整刷新仍由页面完成；本批不声明能中断网络请求或取消后端迁移任务。

Vitest 使用假时钟验证慢请求重叠、任务切换、终态、失败重启、销毁后的迟到结果、概览关闭与恢复、同任务重启的旧响应和空任务。类型检查、前端完整测试、生产构建及 Chrome 86 产物检查共同验证整合。

回滚可独立撤销本批，恢复原页面定时器；没有数据库、后端 API 或生产配置变更。其他表单与展示区继续按后续独立问题拆分，不在本批重写整页。
