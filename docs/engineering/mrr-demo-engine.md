# MRR 演示数据引擎 · 实施记录

只用于本地 Mock 及 GitHub Pages。生产构建、身份与权限、数据库和存储不变；禁止导入真实病案、真实日志及凭据。保留 Pages CSP 和未知接口的失败行为。当前采用浏览器兼容的 vite-plugin-fake-server handler，纯 TypeScript 核心 helper 不放入插件扫描目录。

## M2 第一批：运维与监控

- operations：总览、就绪、维护模式、全面体检、诊断报告、合成影像来源查询、完整性、任务与审计、权限矩阵和样例快照。仅演示内存状态，权限矩阵为明确标注的样例，不代表生产授权。影像来源只匹配指定合成样本，不返回真实地址。
- database：数据库概览、表统计、数据质量检查及样例；数字为演示统计，不代表医院运行指标。检查刷新后更新内存运行 ID 和时间。
- system-errors：24 个合成事件，支持筛选、分页、详情、确认/解决/重开，概览由同一事件集合派生。
- 扩展实际 dist-pages smoke，检查运维/监控/错误中心页面存在数据，维护模式的状态转换、失败校验、异常列表筛选与状态写入，不用 Playwright 替换接口。

本轮未补齐数据关系的主档详情、数据库浏览、导出下载、OCR、外部调阅；运维导出任务仅合成状态展示，不具备真实下载。M3 统一实体关联及数据规模扩充，M4 任务流程，M5 场景控制，M6 持续契约检查。新增接口应补齐同方法、路径和响应 DTO；不能用万能成功响应隐藏缺失。刷新浏览器会重置本轮内存变更。

## M2 第二批：公开状态页

监控中心的 iframe 与独立打开操作使用现有 Vue Router 的解析结果（正式 history 保持 /status，Pages 使用 /MRR/#/status）；状态页返回入口同样使用路由解析。四个公开状态 API 使用同一合成时间轴：90 天日记录、当天分钟记录、3 天前 15 分钟演示维护事件；汇总从同一日记录计算，未来分钟为 NO_DATA，范围外日期明确失败。真实 Pages 冒烟检查内嵌路径、90 天记录、异常日期与事件。浏览器模拟不是实际服务监控。
