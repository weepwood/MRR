# OCR 历史未分类影像处理变更提案

## 风险等级

P1：新增后台本地进程、数据库迁移、持久化授权、自动类型变更与审计。

## 问题与证据

关联 #342、#91、#146、#142、#147；PR #236 只完成 OCR 数据表、类型字典与配置基础。
当前没有 OCR 执行器，人工类型更新未写入 mr_image_type_audit。
用户已确认同机离线 CPU、历史 btype=0、准确优先，明确结果自动归类，疑难页人工审核。
本提案扩展 #91/#146 的单病案、人工确认边界；不取消其隐私、幂等与审计约束。

## 目标与范围

- RapidOCR / ONNX Runtime CPU，显式本地 PP-OCRv5 mobile 模型。
- 先保存 OCR 原文与版本，再运行可解释分类；原文、建议、正式类型分离。
- 单病案任务、有限历史批次、暂停/恢复/取消、失败重试和人工审核。
- 自动处理仅限仍为 0 的有效影像，真实用户明确授权，执行时重新校验账号权限。
- 支持按批次预览和安全回退，不覆盖后续人工操作。

## 非目标

全院全文搜索、结构化表格、手写专项、新扫描自动接入、已分类历史页重识别、云 OCR。
不修复或猜测 #142 的异常归属，不更改现有影像加载机制。

## 必须保持的不变量

- Windows 单机、模块化单体、PostgreSQL 16，不增加 HTTP OCR 服务或中间件。
- 无 Token 返回 401；外部票据/兼容模式不能使用 OCR 接口。
- 禁止用户提供命令、路径或外部图片 URL；禁止联网下载模型。
- 类型变更、建议确认与可信审计同一事务；已有分类不得自动覆盖。
- 不修改已发布 Flyway 迁移；敏感文字不进入日志和公开 Artifact。

## 方案与影响模块

1. ADR、只读 preflight：确认规则与有限范围归属质量；异常页面隔离。
2. 后端 OCR 配置、适配器、受限进程、Mapper、持久化任务；前端单页文字抽屉。
3. 分类规则与发布、统一类型变更事务、审核 API、人工审核界面。
4. 历史批次编排复用单病案任务；游标和任务登记原子提交，有限队列。
5. 独立质量验收后按类别启用自动归类、Windows 离线打包和批次回退。

新增迁移只扩展现有 OCR/分类表及有限历史批次、结果历史；大表索引独立并发构建。
新增 ocr:batch-run、ocr:text-read、classification:auto-apply；不自动赋予普通角色。
自动授权独立于 JWT 有效期，不独立于账号状态和实时权限。

## 默认值与资源边界

1 个 OCR 进程、2 个推理线程、单页 30 秒、协议输出总量 4 MB。
历史每批默认最多 10000 页、游标批量 200，22:00–06:00 Asia/Shanghai。
自动落库和 OCR 默认关闭；失败最多自动重试 2 次，仅重试暂时性错误。
CPU 持续 5 分钟超过 70%、可用内存低于 20% 或调阅 P95 恶化超过 10% 时暂停历史领取。

## 验收与验证计划

- RED→GREEN 验证无权限、伪造身份、超时/超量输出、进程退出、取消/重启及并发竞争。
- PostgreSQL 16 验证迁移、任务租约、唯一约束、游标登记原子性和类型/审计回滚。
- 人工修改与自动操作竞争时不覆盖；回退跳过后续人工改类；源变化使建议失效。
- 院内受控样本不少于 2000 页，按病案划分调参与独立验收集。
- 清晰印刷正文 CER 目标 ≤5%；自动归类准确率目标 ≥99.5%，同时报告覆盖率。
- 独立验收集自动候选至少 600 个且零误分；证据不足的类别只给建议。
- 真实 Windows Server、存储来源、断网启动、PowerShell 5.1、Chrome 86 验证。
- 运行 Maven verify、前端类型/构建/相关测试与仓库治理命令；每阶段独立审查。

## 回滚与恢复

先关闭自动应用，暂停历史领取；关闭 OCR 时终止受控进程，保留结果与审计。
按批次只回退最后变更仍属于该自动操作且版本相同的页面，恢复为 0 并追加审计。
模型/规则使用不可变版本目录；应用回退不删除新增数据表；数据库仅前向修复。

## 尚未确认与上线限制

生产数量、#142 质量基线、目标服务器资源、真实模型精度、调阅基线尚未验证。
开发测试数据全部合成；不得连接生产库或自动启动历史处理证明本提案。
真实质量证据不能由 Mock、预设正确率或开发者自行点击通过代替。
