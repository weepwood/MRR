# PostgreSQL 16 GIN 兼容包含查询隔离实验

## 范围和方法

新建独立合成 PostgreSQL 16.16，保留实际 Flyway、触发器与原精确表达式索引，--trgm 构建 BAH/SJH 原字段 GIN gin_trgm_ops，记录实际 EXPLAIN ANALYZE/BUFFERS、索引名称、有效性、容量和构建时间，兼容查询5秒预算。没有强制planner选择。前后各执行一次1000行相同合成插入并回滚、确认总行数不变。未清空OS缓存，且30m独立造数并行；不是稳定冷缓存/写入吞吐实验。BAH片段按合成值100001，可能匹配其他长编号；不假定其选择性固定。高频2字符为00。稀疏游标从中段afterId开始。

结论：不直接部署GIN；选择性、词长、缓存、写入/更新、GIN pending list及索引维护均需进一步评估。短词无三元组时优化有限；优先精确游标，明确兼容模式无同步COUNT。后续完成三千万级基准再考虑单独较大规模GIN对照，避免影响当前大实验。


## 独立10万行提交写入成本实验（2026-11-25）
