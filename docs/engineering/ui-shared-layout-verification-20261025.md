# 共享布局与组件 UI 完善验证记录

日期：2026-10-25。风险等级：P2（共享样式影响多个页面）。

## 任务与边界

用户明确优先统一全局布局和组件。沿用当前 `ui-dashboard-density` 分支已有视觉体系，在 PR #396 的既有调整上继续收敛；参考 Issue #89 的共享组件要求，本轮不宣称完成该 Issue 的全部样板页迁移。

调用关系为页面 → MrrPageShell / MrrPageHeader / MrrFilterBar / MrrDataTablePanel → MrrSectionCard，以及全局页头、指标卡、Element Plus 样式。复用现有主题、圆角、间距和语义色令牌。没有新增 API、Store、依赖或配置项，没有数据库、权限、审计、影像链路或部署变化。

本轮解决：

- 外层圆角不一致：页头、非紧凑筛选栏、分区卡片、指标卡统一使用卡片圆角令牌。
- 页头标题按固定 28px / 窄屏 24px 排版，缩小英文标签与标题间距。
- 静态指标卡不再悬停抬升；说明文字完整换行，不截断口径。
- 页面壳可收缩；长分区标题和操作区允许换行。
- 窄屏分页将总数/每页条数、翻页导航、跳页分行，页码区内部可换行，保留按钮尺寸与全部操作。
- 工作区背景实色与渐变分离，保留 Chrome 86 的实色回退。
- 按钮使用独立的 2px 键盘焦点轮廓，避免被变体阴影规则覆盖。

原有 `src/types/components.d.ts` 改动与 `test-data/` 未跟踪目录不属于本轮，予以保留。
