## 事实与最小实现

旧页面的 Chromium 可访问树显示两个没有名称的 combobox，关键词仅使用整段 placeholder 作名称。三个 input 均没有显式 label 关联。占位文字在选值后不能持续说明字段用途。

为关键词、角色、账号状态分别添加可见 label，使用 `for` 与 Element Plus 实际 input 的 `id` 关联。标签使用既有文本色，局部字段采用网格间距，操作组底部与输入对齐；沿用原字段宽度、窄屏换行和 33px 控件高度。没有改变页面脚本或共享筛选栏。
