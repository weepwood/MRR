## 安装及安全前向恢复顺序

1. **授权和准备**：确认副本隔离、执行/复核人、备份与可恢复证据、JDK21/PG16/Windows、服务账号、NTFS ACL、实际各卷空间及WAL余量；在院内保存配置/密钥、数据、影像及归档摘要。
2. **候选核验**：检查同轮 manifest 及所有外层哈希、ZIP内部 SHA256SUMS、VERSION 和迁移上下限；禁止不匹配、过期或不完整的候选进入部署。
3. **首次安装/更新**：仅授权测试服务器，依 [Windows原生部署手册](../../deploy/windows/README.md) 使用 install.ps1 或 mrrctl/Manager，外置配置及服务身份原样保护；不在生产运行Docker/Vite/git pull，不自动启动未批准功能。
4. **恢复演练**：按手册 database-recovery.ps1 Backup/Verify/RestoreToEmptyReplica，在授权空副本验证恢复、Flyway、权限、实际读图、耗时与RPO/RTO；严禁生产目标或覆盖已有备份。
5. **上线前复核**：检查 manifest/actuator/info、Nginx同源、401/403及撤销、健康、维护/降级、实际影像Range、导出、日志及业务冒烟，完成原矩阵和签字。
6. **异常停止条件**：版本/哈希不符、迁移失败、容量不足、隐私或权限失败、存储异常或现场证据缺失，停止推进；使用现有维护模式与批准的关闭功能入口，保存证据并安全前向修复。不得直接回退不具备持久化撤销的旧应用，不能借数据库恢复覆盖当前审计/撤销。分区回退须经批准并按 ADR-0010 独立流程，不自动执行。

正式发布与医院实际启用需分别批准；候选准备不授权执行生产操作。
