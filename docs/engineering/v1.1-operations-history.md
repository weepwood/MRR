## Nginx 固定语法检查

- APP_OPERATIONS_NGINX_ENABLED 默认 false；仅 Windows，本地管理员受控 MRR_ROOT（必须为本地绝对驱动器路径，非 UNC）。仅固定 runtime/nginx/nginx.exe、runtime/nginx 与 config/nginx/nginx.conf，要求实际路径与规范化路径一致；不接受来自 HTTP 的命令、路径、额外参数，不走 shell、不提权、不返回原始输出。
- GET 只返回状态及配置大小/修改时间，需 system:read；POST /api/v1/operations/nginx/check 需 system:read AND system:manage。固定 -p/-c/-t，8秒等待，强制终止并保留许可直到进程实际退出；不重载或启停、不修改配置。语法校验可能按 Nginx 自身行为打开或创建日志等文件，启用前必须核对安装目录、包含文件和二进制的 Windows ACL；不得允许低权限用户替换这些文件。
- 当前仅元数据及语法检查，不提供运行服务/版本/监听探测、日志尾部或在线配置写入。尚未在 Windows Server 测试环境运行真实 nginx -t；本地模拟进程测试不能替代现场验收。保持默认关闭。回滚禁用并撤销代码即可。
