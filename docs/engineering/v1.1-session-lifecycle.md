## 规格与实施

- Store：显式登录、设置会话、清除会话推进代次；资料刷新核对会话代次、请求代次、原始 token；迟到成功与失败不回填。注销本地先清理，独立 axios 请求仅携带捕获的旧 token、5秒超时，不经过当前账号拦截器；不保证网络异常时服务端撤销成功，不改后端黑名单。auth/me 是候选会话唯一允许的既有 token 绑定验证接口，其他绑定请求仍要求已验证会话。
- Layout：已验证会话才渲染主 RouterView/LinkView，sessionEpoch 切换重建缓存树；不宣称所有全局状态/请求都已审计。公共 useCrudList 可选会话标识与权限监听，重置列表、总数、分页、查询、加载、结果代次及附属状态，拒绝失效响应。三个调用点日志、影像审计、运行错误中心接入；日志和运行错误初始 Request ID 不作为跨会话默认重置值。
- 日志/审计/运行错误相关 API 传入原 token，复用现有 Axios 会话绑定；迟到401/428不应用至不同 token 新会话，普通查询代次逻辑保持。运行错误概览及模块清空、模块请求代次；影像审计统计、详情、导出代次，详情校验 ID 及已有 Request ID、加载和失败/重试，不回退摘要，关闭/会话变化取消详情；导出结果失效时不创建下载。已完成的本地文件不在删除范围。
- 风险边界：同一 token 的后端异步权限变化仍依赖服务端拒绝与客户端资料刷新，尚未逐页覆盖所有未绑定 API、权限撤销后的静默刷新拒绝、全局菜单/通知和跨标签页。公共列表清理不是全站所有状态的隔离证明；未验证真实服务端注销链或医院运行环境。
- 非目标：不修改真实医疗数据、后端认证及授权策略、数据库迁移、生产发布。回滚：独立前向修复或回退本前端提交，保留既有后端权限与原发布基线；若发现跨账号残留阻塞合并，不放宽门禁。
