## 实际功能与边界

- GET /api/v1/system/data-relations/archives/{archiveId}/scans 仅 system:read AND record:read，private,no-store；参数 archiveId>0、limit 1..100、afterId 正整数、afterPage 不可脱离 afterId。只返回有效扫描的 ID、archiveId、页码、类型、上传标志和迁移状态，不返回文件名、路径、原始摘要、病案号或身份证。不存在/无影像的病案返回空集合。
- 复用 idx_mr_scan_archive_pages(archive_id,pages,id)，分非空页码 tuple cursor 与 NULL 页码 ID cursor 两阶段，最多取 limit+1 个结果用于下一游标，不进行全表计数，不改变原详情50样本合同。5秒只读事务；实时分页不是固定快照，并发变化可能需要刷新；无新迁移，不重新执行三千万基准。
- 工作台每组50条，前后游标、刷新、错误、空列表、加载状态。只保留当前页数据及游标历史，病案/权限/会话变化清除选择、取消旧请求、拒绝迟到与跨病案/重复/无效影像响应。点击选择后才读取原图。原图与 OCR 按宽度并列或换行。
- 原 OcrPanel 新增 inline 模式，显式打开/收起，已展开时切换本页内影像继续展示，但重置旧文字、任务与操作代次；既有独立档案袋仍使用 ElDrawer。权限、服务端身份检查、手工任务操作保留，不默认识别、不自动分类、不修改真实医疗数据。
- Mock 从共享合成有效扫描数据分页，合成数据页码均非空；真实 PG 测试覆盖 NULL 及重复页码。静态路由匹配180/220，40缺失、0重复；新增接口纳入已有 data-relations 严格门禁。
