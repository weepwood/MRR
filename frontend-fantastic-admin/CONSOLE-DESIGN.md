# MRR Console 设计文档入口

本文件保留旧链接入口，现行视觉与交互规范统一维护在 [DESIGN.md](DESIGN.md)。工程实现规则见 [ENGINEERING.md](ENGINEERING.md)，整体产品、架构与验收导航见 [项目设计导航](../docs/design/README.md)。

旧版独立数值与现有代码存在冲突，已经停止作为实现依据。后续不要在本文件复制按钮、圆角、字体、侧栏或状态规则，也不要根据旧版描述反向修改页面。历史内容可通过 Git 历史追溯。

阅读时区分：

- 架构与权限约束：以 [ARCHITECTURE.md](../ARCHITECTURE.md)、ADR 和实际后端实现为准。
- UI 当前值与目标约束：以 [DESIGN.md](DESIGN.md) 的来源及实施状态为准。
- 产品规格草稿：见 [PR #530](https://github.com/weepwood/MRR/pull/530)，尚未作为正式产品承诺。
- 医院实际启用：以固定候选及 [院内验收记录](../docs/engineering/hospital-replica-acceptance-record.md) 为准，不以文档存在或页面可见判断完成。
