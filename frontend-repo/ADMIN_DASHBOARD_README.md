# 后台管理系统功能说明

## 概述

本项目已成功构建了一个完整的后台管理页面，集成了测试和日志等功能。新的管理面板提供了全面的系统管理功能。

## 主要功能

### 1. 仪表板 (Dashboard)
- **统计概览**: 显示总用户数、病案总数、今日新增、在线用户等关键指标
- **最近活动**: 实时显示系统最近的活动记录
- **系统状态**: 实时监控CPU、内存、磁盘使用率
- **可视化图表**: 直观展示系统运行状态

### 2. 用户管理 (User Management)
- **用户列表**: 查看所有系统用户信息
- **用户操作**: 添加、编辑、删除用户
- **权限管理**: 管理用户角色和权限
- **状态监控**: 查看用户登录状态和最后登录时间

### 3. 病案管理 (Record Management)
- **病案列表**: 查看所有病案记录
- **搜索功能**: 支持按病案号、患者姓名搜索
- **状态管理**: 查看病案处理状态
- **批量操作**: 支持批量导出等操作

### 4. 系统测试 (System Testing)
- **API接口测试**: 完整的HTTP请求测试工具
  - 支持GET、POST、PUT、DELETE等方法
  - 自定义请求头和请求体
  - 实时显示响应结果和性能指标
- **身份证加解密测试**: 测试身份证号加密解密功能
  - 加密测试
  - 解密测试
  - 端到端测试
- **功能测试**: 快速测试系统各项功能
  - 多选功能测试
  - 打印页面测试
  - 图片画廊测试

### 5. 系统日志 (System Logs)
- **实时日志**: 显示系统运行日志
- **日志级别**: 支持按级别过滤（错误、警告、信息、调试）
- **日志管理**: 刷新、清空日志功能
- **自动记录**: 自动记录用户操作和系统事件

### 6. 系统监控 (System Monitoring)
- **性能监控**: 实时监控CPU、内存、磁盘使用率
- **网络状态**: 显示本地IP、公网IP、网络位置等信息
- **浏览器信息**: 显示用户浏览器详细信息
- **连接状态**: 监控在线状态和网络连接

### 7. 系统设置 (System Settings)
- **基本设置**: 系统名称、文件大小限制、会话超时等
- **安全设置**: 密码策略、登录限制、IP白名单等
- **通知设置**: 邮件通知、系统警报配置
- **维护设置**: 维护模式、数据清理、性能监控等
- **配置管理**: 支持导入导出系统配置

## 技术特性

### 1. 响应式设计
- 支持桌面端和移动端
- 自适应布局

### 2. 实时更新
- 系统状态实时监控
- 日志实时更新
- 自动错误捕获

### 3. 安全性
- 路由权限控制
- 操作日志记录

### 4. 可扩展性
- 模块化组件设计

## 访问方式

1. **登录系统**: 使用管理员账号登录
2. **进入管理面板**: 在管理页面点击"完整管理面板"按钮
3. **或直接访问**: 访问 `/admin-dashboard` 路径

## 使用说明

### 1. 系统测试
- 在"系统测试"页面可以测试API接口
- 支持身份证加解密功能测试
- 可以快速测试系统各项功能

### 2. 日志查看
- 在"系统日志"页面查看所有系统日志
- 支持按级别过滤日志
- 可以清空或刷新日志

### 3. 系统监控
- 在"系统监控"页面查看系统运行状态
- 实时监控系统性能指标
- 查看网络和浏览器信息

### 4. 系统设置
- 在"系统设置"页面配置系统参数
- 支持导入导出配置
- 可以设置各种系统选项

## 注意事项

1. 所有管理功能都需要管理员权限
2. 系统会自动记录用户操作日志
3. 建议定期查看系统监控和日志
4. 重要操作前请确认设置正确
