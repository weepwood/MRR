# 病案图片多选打印功能

## 功能概述

新增了病案图片的多选功能和专门的打印页面，用户可以通过悬浮在缩略图上的圆点按钮选择多张图片，然后跳转到专门的打印页面进行打印操作。

## 主要功能

### 1. 多选功能
- **悬浮选择按钮**: 鼠标悬浮在缩略图上时，右上角会出现圆点选择按钮
- **多选状态管理**: 支持选择多张图片，选中的图片会有绿色边框和背景
- **选择工具栏**: 当有选中图片时，会显示工具栏，包含：
  - 已选择图片数量显示
  - 清除选择按钮
  - 全选当前类型按钮
  - 打印选中图片按钮

### 2. 打印页面
- **专业打印界面**: 专门设计的打印页面，主题与原页面保持一致
- **打印设置**: 支持多种打印选项：
  - 纸张大小 (A4, A3, Letter)
  - 打印方向 (纵向, 横向)
  - 每页图片数 (1张, 2张, 4张)
  - 显示页码选项
  - 显示图片信息选项
- **图片预览**: 实时预览打印效果
- **多种操作**: 支持预览打印、下载PDF等功能

## 使用方法

### 1. 选择图片
1. 进入病案图片浏览页面
2. 将鼠标悬浮在任意缩略图上
3. 点击右上角出现的圆点按钮选择图片
4. 选中的图片会有绿色边框标识

### 2. 管理选择
- 点击"清除选择"按钮取消所有选择
- 点击"全选当前"按钮选择当前类型的所有图片
- 工具栏会显示已选择的图片数量

### 3. 打印图片
1. 选择完要打印的图片后，点击"打印选中图片"按钮
2. 系统会在新窗口中打开打印页面
3. 在打印页面中调整打印设置
4. 点击"打印"按钮执行打印操作

## 技术实现

### 文件结构
```
src/
├── components/
│   ├── ImageGalleryEl-3.vue    # 主图片浏览组件（已修改）
│   └── PrintPage.vue           # 新增打印页面组件
├── utils/
│   └── printUtils.js           # 打印相关工具函数
└── router/
    └── index.js                # 路由配置（已更新）
```

### 主要修改

#### ImageGalleryEl-3.vue
- 添加了多选状态管理 (`selectedImages`, `isMultiSelectMode`)
- 新增了选择按钮UI和交互逻辑
- 添加了多选工具栏
- 实现了数据传递到打印页面的功能

#### PrintPage.vue
- 全新的打印页面组件
- 支持多种打印设置
- 响应式设计，适配不同屏幕尺寸
- 包含打印样式优化

#### printUtils.js
- 病案类型名称映射
- 打印数据验证
- 打印样式生成等工具函数

#### 路由配置
- 添加了 `/print` 路由指向打印页面
