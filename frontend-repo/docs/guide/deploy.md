# 构建与部署

## 本地预览文档产物

```bash
npm run docs:build
npm run docs:preview
```

## 产物路径

- 文档构建输出：`public/docs`
- VitePress 访问前缀：`/docs/`

## 部署方式

### 方式 1：作为主站子路径部署（推荐）

适用场景：文档与业务前端一起部署。

1. 执行 `npm run build`（会自动先执行 `docs:build`）。
2. 部署 `dist` 与 `public/docs` 到同一站点。
3. 确保站点可访问 `/docs/` 路径。

### 方式 2：独立静态站点部署

适用场景：文档独立域名或 CDN 托管。

1. 执行 `npm run docs:build`。
2. 将 `public/docs` 整体上传到静态托管目录。
3. 若部署根路径不是 `/docs/`，需同步修改 `config.mts` 中 `base`。

## 发布检查清单

1. 首页、指南、部署、文档索引菜单可正常跳转。
2. 中文文件名页面（如“病案管理功能说明”）可以访问。
3. 本地搜索可返回结果。
4. 无死链和 404 页面。

## 回滚建议

1. 保留最近两版 `public/docs` 产物。
2. 发布失败时直接切回上一版目录。
3. 回滚后重新执行页面抽样检查（首页、指南、关键功能文档）。
