# 病案管理功能说明

## 功能概述
病案管理模块提供了完整的病案数据管理功能，包括查询、查看、编辑、删除等操作。

## 后端接口

### 1. 获取病案列表（分页）
- **接口**: `/v1/scan-api/page`
- **请求方式**: GET
- **请求参数**: 
  - `page`: 页码（从 1 开始）
  - `size`: 每页数量
  - `keyword`: 搜索关键词（可选）
- **响应格式**: 
``json
{
  "code": 200,
  "timestamp": "2026-03-18T21:04:13.934",
  "message": null,
  "data": {
    "total": 123,
    "size": 100,
    "page": 1,
    "list": [
      {
        "id": 1,
        "brxh": "666666",
        "bah": "00789123",
        "filename": "0001.jpg",
        "btype": 1,
        "pages": 1,
        "openerNo": "WHL",
        "uploadDate": "2024-04-07T08:09:00.000+00:00",
        "uploadFlag": 1,
        "folder": "24.04.07"
      }
    ]
  }
}
```

**注意**：后端返回的数据结构可能是以下两种格式之一：
1. `{ total: N, list: [...] }` - 使用 `list` 字段
2. `{ total: N, records: [...] }` - 使用 `records` 字段

前端已兼容这两种格式。

### 2. 其他接口
- 根据病案号获取详情：`/v1/scan-api/{bah}`
- 更新病案信息：`/v1/scan-api/{id}` (PUT)
- 删除病案：`/v1/scan-api/{id}` (DELETE)
- 批量下载：`/v1/scan-api/batch-download` (POST)

## 数据字段说明
- `id`: 病案记录 ID
- `brxh`: 病人序号
- `bah`: 病案号
- `filename`: 文件名
- `btype`: 病案类型（共 14 种）
  - 1: 01-病案首页
  - 2: 02-病程记录
  - 3: 03-手术记录
  - 4: 04-术后病程录
  - 5: 05-护理记录
  - 6: 06-会诊单
  - 7: 07-特殊检查
  - 8: 08-检验单
  - 9: 09-医嘱
  - 10: 10-体温单
  - 12: 12-出院记录
  - 13: 13-大病历
  - 14: 14-其它
- `pages`: 页数
- `openerNo`: 扫描负责人
- `uploadDate`: 上传日期
- `uploadFlag`: 上传状态标识（1-已上传，0-未上传）
- `folder`: 存储文件夹

## 主要功能

### 1. 查询功能
- 支持按病案号或患者姓名搜索
- 支持分页查询（10/20/50/100 条/页）
- 回车键快速搜索

### 2. 查看详情
- 点击"查看"按钮查看完整病案信息
- 以描述列表形式展示所有字段

### 3. 编辑功能
- 支持修改文件名、类型、页数、开单医生等信息
- 病案号和病人序号不可修改
- 保存前自动验证数据

### 4. 删除功能
- 删除前弹出确认对话框
- 删除成功后自动刷新列表

### 5. 批量操作
- 支持多选病案记录
- 预留批量下载和导出功能接口

### 6. 刷新功能
- 手动刷新数据按钮
- 加载时显示 Loading 状态

## API 接口封装
在 `src/utils/api.js` 中新增了以下接口：

```javascript
// 获取病案列表
export function getRecords(params = {})

// 根据病案号获取病案详情
export function getRecordByBah(bah)

// 更新病案信息
export function updateRecord(id, data)

// 删除病案
export function deleteRecord(id)

// 批量下载病案
export function batchDownloadRecords(ids)
```

## 使用 Element Plus 组件
- `el-table`: 数据表格展示
- `el-pagination`: 分页控件
- `el-dialog`: 详情和编辑对话框
- `el-form`: 表单编辑
- `el-tag`: 状态标签
- `el-descriptions`: 详情描述列表

## 注意事项
1. 确保后端接口已正确配置 CORS
2. 需要在登录认证后访问接口（自动携带 token）
3. 批量下载和导出功能需要后端配合实现
4. 日期格式已转换为本地化显示
