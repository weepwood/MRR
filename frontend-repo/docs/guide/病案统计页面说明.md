# 病案数据统计页面说明

## 📊 功能概述

病案数据统计页面（`RecordsStatisticsView.vue`）是一个专业的数据可视化仪表盘，用于展示病案管理系统的统计信息和趋势分析。

## ✨ 主要功能

### 1. 总体统计卡片

展示 4 个核心指标的实时数据：

- **总记录数**：系统中医务记录的总数量
- **总页数**：所有病案记录的累计页数
- **唯一病案号数**：不重复的病案号数量
- **数据概览**：快速查看整体数据规模

### 2. 按类型分布统计

以卡片形式展示不同类型病案的分布情况：

- **普通病案**：常规医疗记录
- **质控病案**：质量控制相关记录
- **高拍病案**：高拍仪扫描的记录
- **进度条可视化**：直观显示各类型占比

每个类型卡片包含：
- 类型图标和名称
- 记录数量和页数统计
- 百分比进度条
- 悬停动画效果

### 3. 日期趋势图表

使用 SVG 折线图展示数据变化趋势：

- **记录数趋势**：蓝色渐变折线，展示每日记录数变化
- **数据点标记**：圆形标记点，支持悬停查看详情
- **网格背景**：辅助网格线，便于读取数值
- **日期标签**：智能显示部分日期，避免拥挤
- **图例说明**：清晰的图表标识

特点：
- 自动排序日期数据（升序）
- Y 轴智能缩放（百位取整）
- 面积图填充效果
- 响应式交互
- **自适应宽度**：根据容器自动调整图表尺寸

### 4. 病案明细列表 🆕

展示具体的病案记录详细信息：

#### 表格列说明
- **序号**：自动编号
- **病案号**：可点击链接，显示病案编码
- **CID**：病例类型标识（B/M 等）
- **开启号**：显示 openerNo，NULL 显示为"-"
- **日期**：格式化后的日期（YYYY-MM-DD）
- **类型**：带颜色标签（普通/质控/高拍）
- **页数**：实际页数，超过 50 页高亮显示

#### 分页功能
- **每页数量**：支持 50/100/200/500 条
- **总记录数**：显示数据总量
- **页码导航**：上一页、下一页、数字跳转
- **快速跳转**：直接输入页码定位

#### 排序功能
- 支持按各列字段升序/降序排列
- 默认按日期降序排列
- 点击表头即可切换排序

#### 特殊处理
- 自动过滤 null 值记录
- NULL 值显示为"-"
- 页数>50 时橙色高亮
- 空数据时显示友好提示

## 🎨 设计风格

采用 MonitoringView 的苹果官网风格：

### 视觉元素
- **渐变背景**：柔和的线性渐变
- **卡片设计**：圆角 18px，微妙阴影
- **顶部彩条**：4px 彩色装饰条区分类型
- **流畅动画**：cubic-bezier(0.4, 0, 0.2, 1) 缓动函数
- **悬停效果**：向上移动 + 阴影增强

### 配色方案
- **总记录数**：蓝色系 (#0071e3 → #005bb5)
- **总页数**：红色系 (#ff2d55 → #d41a4a)
- **唯一病案号**：绿色系 (#34c759 → #28a745)
- **数据概览**：橙色系 (#ff9500 → #ff7f00)
- **趋势图表**：蓝青渐变 (#0071e3 → #00c6fb)

## 🔌 接口对接

已对接四个后端接口，所有接口都封装在 `@/utils/api.js` 中：

### 1. `/statistics-api/summary` - 总体统计
- **API 函数**: `getStatisticsSummary()`
- **返回数据**: 总记录数、总页数、按类型分布统计

### 2. `/statistics-api/date-summary` - 日期趋势
- **API 函数**: `getStatisticsDateSummary()`
- **返回数据**: 按日期排序的记录数和页数变化

### 3. `/statistics-api/dashboard` - 仪表盘
- **API 函数**: `getDashboardData()`
- **返回数据**: 概览信息、最近趋势、Top 病案号

### 4. `/statistics-api?page=1&size=100` - 明细列表 🆕
- **API 函数**: `getStatisticsList(page, size)`
- **返回数据**: 具体病案记录的分页列表
- **参数说明**:
  - `page`: 页码（默认 1）
  - `size`: 每页数量（默认 100）
- **支持分页**: 前端分页控件联动

所有接口都支持统一的响应格式处理：
```
{
  "code": 200,
  "timestamp": "2026-03-18T23:31:52.254",
  "message": null,
  "data": { ... },
  "total": null
}
```

### 🎯 图表自适应特性

#### 1. 宽度自适应
```
// 监听窗口大小变化
window.addEventListener('resize', updateChartWidth)

// 动态计算 SVG 宽度
const updateChartWidth = () => {
  if (chartContainerRef.value) {
    const containerWidth = chartContainerRef.value.offsetWidth
    svgWidth.value = Math.max(containerWidth * 0.95, 600) // 使用容器 95% 宽度，最小 600px
  }
}
```

#### 2. X 轴智能分布
```
// 根据数据点数量和数据宽度动态计算步长
const xStep = computed(() => {
  if (sortedDateData.value.length <= 1) return chartWidth.value
  return chartWidth.value / (sortedDateData.value.length - 1)
})
```

#### 3. 响应式优势
- ✅ **适配各种屏幕尺寸**：从手机到大屏显示器都能完美展示
- ✅ **窗口缩放友好**：浏览器窗口大小变化时自动重绘
- ✅ **最佳视觉体验**：始终利用可用宽度，提供最大图表区域
- ✅ **性能优化**：仅在必要时重新计算，避免频繁渲染

## 🔧 常见问题

### 页面无法滚动问题

**问题描述**：整个页面无法上下滚动，内容被截断。

**原因**：`App.vue` 中设置了 `html, body { overflow: hidden; }` 阻止了全局滚动。

**解决方案**：已在 App.vue 中移除该设置，允许页面正常滚动。修改如下：

```
/* 修改前 */
html, body {
  height: 100%;
  overflow: hidden;  /* ❌ 阻止滚动 */
}

/* 修改后 */
html, body {
  height: 100%;
  /* ✅ 允许正常滚动 */
}
```

**影响范围**：此修改会影响所有页面的滚动行为，但不会影响其他布局效果。
