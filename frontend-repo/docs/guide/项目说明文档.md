## 1. 项目概述

PMR（病案翻拍管理）是一个面向病案图像检索、浏览、分类、统计与打印的业务系统，当前代码以多仓目录协同方式组织：

- `frontend-repo`：Vue 3 + Vite 前端应用及文档站（VitePress）
- `backend-repo`：Spring Boot + MyBatis + SQLite 后端服务
- `mrr-db`：数据库 schema 与结构定义

核心业务目标：

1. 按身份证或病案号快速定位病案。  
2. 支持病案图片分类、多选、批量打印与下载。  
3. 提供后台管理能力（统计、日志、监控、设置等）。  
4. 建立前后端接口对齐、文档化和质量门禁流程。

## 4. 系统架构与调用链路

### 4.1 总体调用关系

1. 浏览器访问前端（Vite Dev Server / 静态产物）。
2. 前端通过 `vite.config.js` 代理调用后端接口。
3. 后端经 MyBatis 访问 SQLite，并按业务返回统一结构。
4. 前端完成展示、筛选、打印与管理操作。

### 4.2 开发环境代理映射

来源：`frontend-repo/vite.config.js`

- `/api/*` → `http://localhost:18045/v1/*`
- `/searchApi/*` → `http://localhost:18045/v2/*`
- `/loginApi` → `http://localhost:18045/login`

## 5. 前端模块说明

### 5.1 路由与页面

来源：`frontend-repo/src/router/index.js`

- `/login`：登录页
- `/admin`：管理入口页（需登录）
- `/admin-dashboard`：后台总面板（需登录）
- `/admin/statistics`：病案统计页（需登录）
- `/print`：打印页
- `/:idCard`：按身份证进入病案图片浏览页
- `/admin/:idCard/:bah`：后台按身份证+病案号浏览
- `/docs/*`：重定向到 `/docs/index.html`

### 5.2 登录与鉴权

来源：`Login.vue` + `router/index.js` + `utils/api.js`

- 登录成功后，将 `token` 写入 `localStorage`。
- 管理路由通过 `beforeEach` 守卫校验 `token`。
- `authApi` 自动在请求头注入 `Authorization: Bearer <token>`。
- 当接口返回 `401/403` 时，前端会清理 token 并刷新页面。

### 5.3 主要业务能力

1. 病案检索与图片浏览  
   - 按身份证查询病案列表。  
   - 按病案号加载图片，支持类型过滤与缩略图/列表视图。  
   - 支持修改图片类型（OCR 分类纠正）。

2. 多选与打印  
   - 支持多选图片、按类型批量选择。  
   - 通过独立打印页配置纸张、页边距、旋转等参数。  
   - 使用 `sessionStorage` 在主页面与打印页间传递数据。

3. 后台管理  
   - 仪表盘、病案管理、统计、系统日志、系统监控、设置面板。  
   - 包含管理员退出登录确认弹窗（已统一视觉方案）。

4. 文档中心  
   - 通过 `/docs` 集成 VitePress 文档站。  
   - 支持开发、构建、预览三种文档工作流。

### 5.4 前端工具层

- `utils/api.js`：统一 Axios 实例、拦截器与接口函数
- `utils/logger.js`：前端日志管理与全局错误监听
- `utils/decrypt.js`：身份证加解密（测试/兼容用途）
- `utils/printUtils.js`：打印相关辅助函数

## 6. 后端模块说明

### 6.1 主要 Controller（按目录）

来源：`backend-repo/src/main/java/com/zjcxph/imgapi/controller`

- `UserController`：登录与用户相关接口
- `ImageController`：病案图片读取、下载、类型更新
- `SearchController`：身份证/密文检索病案
- `ScanController`：病案扫描记录 CRUD 与批量下载
- `StatisticsController`：统计汇总与趋势数据
- `LogController`：系统访问日志查询
- `SystemInfoController`：系统运行状态与健康信息

### 6.2 配置与运行时参数

来源：`backend-repo/src/main/resources/application.properties`

可通过环境变量覆盖的关键项：

- `SERVER_PORT`（默认 `18045`）
- `SPRING_DATASOURCE_URL`（默认 `jdbc:sqlite:./data/scan_test.db`）
- `IMAGE_URL`
- `IMAGE_BASE_PATH`
- `IMAGE_USERNAME`
- `IMAGE_PASSWORD`
- `AES_SECRET_KEY`

### 6.3 API 文档入口

- Swagger UI：`http://localhost:18045/v1/swagger-ui/index.html`

## 7. 核心 API 对齐（前后端）

来源：`backend-repo/API_CONTRACT.md` + `frontend-repo/src/utils/api.js`

### 7.1 认证

- `POST /login`：登录，返回 token

### 7.2 图片

- `GET /v1/img-api/{bah}`
- `GET /v1/img-api/download/{BAH}`
- `GET /v1/img-api/image/{...}`
- `PUT /v1/img-api/updateImageType/{id}`

### 7.3 检索

- `GET /v2/search/getBAHByID/{idCard}`
- `GET /v2/search/getBAHByEncryptID`
- `GET /v2/search/getBAHByEncryptIDLegacy`（兼容）

### 7.4 扫描记录

- `GET /v1/scan-api/page`
- `GET /v1/scan-api/{id}`
- `PUT /v1/scan-api/{id}`
- `DELETE /v1/scan-api/{id}`
- `POST /v1/scan-api/batch-download`

### 7.5 统计、日志、监控

- `GET /v1/statistics-api/*`
- `GET /v1/logs-api/search`
- `GET /v1/system/*`

## 8. 数据模型

来源：`mrr-db/schema.sql`

核心表：

- `mr_patient`：患者与病案关联信息
- `mr_scan`：病案扫描明细（页码、类型、路径等）
- `mr_statistics`：统计汇总相关数据
- `access_log`：访问日志
- `mr_user`：用户信息

## 12. 安全与风险说明

1. 前端 token 当前存储在 `localStorage`，请在生产环境配合更严格的会话策略。  
2. `utils/decrypt.js` 中包含示例密钥常量，仅可用于本地测试，不得用于生产密钥管理。  
3. 后端 `application.properties` 默认值仅用于开发环境，生产环境必须通过环境变量覆盖。  
4. 后端依赖与注释已提示不建议直接暴露公网部署，需结合网关与访问控制。  

## 13. 已知事项

1. `frontend-repo` 的 `package.json` 中存在 `server/dev:server` 脚本，但当前仓库内未提供 `frontend-repo/server/index.js`，前后端请分别在 `frontend-repo` 与 `backend-repo` 启动。  
2. 后端测试目前受运行环境/数据影响，质量门禁阶段默认以“可构建”为主。
