# MRR 0.6.1

发布日期：2026-07-22

## 本次发布重点

### 外部影像调阅与开发者兼容模式

- 外部系统 Ticket 调阅统一复用现有影像档案袋，减少重复页面和权限分叉。
- 外部会话由后端 Context 持续验证，浏览器存储和 URL 参数不能扩大授权范围。
- 旧档案袋兼容模式默认关闭，只允许可信代理、客户端 IP/CIDR 白名单和只读接口，并完整记录访问审计。
- 取消匿名病案详情查询绕过审计的入口，下载、PDF 导出、图片类型修改和后台管理继续要求正式权限。

### main 主分支与工程治理

- `main` 正式成为唯一主分支，Actions、贡献流程、安装文档、Agent 指令和架构图全部完成迁移。
- 增加自动检查，阻止活跃文件重新引用旧 `dev-no-login`，并检查压缩 Draw.io 中隐藏的错误认证说明。
- GitHub Actions 已覆盖后端完整 `verify`、前端 TypeScript/Lint/Vitest/Chromium E2E、监控配置、文档和 Windows 离线包。

### 发布可靠性

- 发布包统一包含后端 JAR、前端、用户/内部文档、Windows 运维脚本、`manifest.json`、`release-baseline.json` 和 `SHA256SUMS`。
- 后端、前端和文档都写入同一产品版本与 Git Commit，Windows 工作流会验证构建身份。
