# MRR 0.6.2

发布日期：2026-07-22

## 发布重点

### Windows 离线包内置 Nginx

- 正式安装包包含 Nginx for Windows 1.31.3 和 WinSW 2.12.0。
- 内网服务器只需要预装 PostgreSQL 16 与 JDK 21，不再单独准备 Nginx 和 WinSW。
- 包内包含运行时版本来源、许可文件和两级 SHA-256 校验清单。

### Nginx 控制中心

安装后可双击：

```text
C:\MRR\ops\nginx-control.cmd
```

也可使用 PowerShell：

```powershell
$nginx = 'C:\MRR\ops\nginxctl.ps1'
& $nginx status
& $nginx start
& $nginx stop
& $nginx restart
& $nginx test
& $nginx reload
& $nginx pause
& $nginx resume
```

`pause` 不会挂起进程，而是开启 503 维护模式；`resume` 会在配置检查通过后恢复访问。

## 首次安装

```powershell
.\deploy\windows\install.ps1 `
  -Root C:\MRR `
  -JavaHome 'C:\Program Files\Java\jdk-21'
```

安装脚本会验证包内运行时、生成 Nginx 配置、安装 `MRR-Backend` 与 `MRR-Gateway` 服务，并执行 `nginx -t`。

## 升级后核对

1. 运行 `C:\MRR\ops\nginx-control.cmd` 检查 Nginx 状态和配置。
2. 检查 `C:\MRR\runtime\versions.json` 中的运行时版本。
3. 校验发布包顶层 `SHA256SUMS` 和 `runtime\SHA256SUMS`。
4. 验证登录、病案查询、影像访问、外部 Ticket、审计、维护模式和恢复访问。
