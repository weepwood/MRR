# MRR 0.6.3

发布日期：2026-07-22

## 发布重点

### 用户注册与管理员审核

- 用户可在登录页面提交注册申请；
- 新账号初始状态为待审核，不能直接登录；
- 管理员可在用户管理中审核通过并分配角色，或填写原因拒绝申请；
- 注册、审核通过和审核拒绝均纳入审计；
- 数据库迁移增加注册联系方式、申请说明、申请时间和审核信息等字段。

### Windows 一键管理中心

安装完成后可双击：

```text
C:\MRR\ops\MRR-管理中心.cmd
```

兼容 ASCII 入口：

```text
C:\MRR\ops\MRR-Manager.cmd
```

管理中心集中展示产品版本、Git Commit、后端、Nginx、健康状态、维护模式和磁盘空间，并提供一键启停、重启、维护暂停/恢复、ZIP 部署、版本列表、系统诊断、Nginx 检查/重载和目录快捷入口。

所有操作继续复用 `mrrctl.ps1` 与 `nginxctl.ps1`，不会绕过发布清单、SHA-256、健康检查、构建身份和回滚限制。

### Windows 脚本编码兼容

- 所有 `deploy/windows/**/*.ps1` 使用 UTF-8 with BOM，兼容 Windows PowerShell 5.1；
- 所有 `deploy/windows/*.cmd` 使用 UTF-8 without BOM；
- CMD 入口在处理中文前执行 `chcp 65001`；
- 管理中心支持 `-SelfTest` 无界面检查；
- GitHub Actions 使用 Windows PowerShell 5.1 与 Windows ComSpec 验证编码、语法和真实入口。

## 其他修复

- 修复停止全部服务后重新启动仍处于维护模式的问题；
- 修复管理中心后台调用时参数未逐项传递的问题；
- 修复部分 ZIP 工具处理中文源入口文件名不一致的问题；
- 正常双击保持隐藏控制台，自检模式保留可靠退出码。

## 首次安装

```powershell
.\deploy\windows\install.ps1 `
  -Root C:\MRR `
  -JavaHome 'C:\Program Files\Java\jdk-21'
```

## 数据库与回滚

- 最低兼容迁移：`20260715113552`；
- 最高兼容迁移：`20260722221000`；
- 配置结构版本：`1`；
- 不允许仅替换回 0.6.2 应用文件；回滚前必须恢复发布前数据库和配置备份，并重新执行兼容性验证。

## 升级后核对

1. 确认登录页可以提交注册申请，待审核账号无法登录；
2. 使用管理员账号审核通过或拒绝一条申请，并核对审计记录；
3. 双击 `C:\MRR\ops\MRR-管理中心.cmd`，确认状态展示和常用操作；
4. 验证启动、停止、重启、暂停访问和恢复访问；
5. 执行系统诊断和 Nginx 配置检查；
6. 校验正式 ZIP 顶层 `SHA256SUMS` 与 `runtime\SHA256SUMS`；
7. 验证病案查询、影像访问、外部 Ticket 和审计功能。
