# MRR 0.6.5

发布日期：2026-07-23

## 发布重点

### 核心业务数据交换中心

- 将患者、统计、档案装箱和扫描记录的导入导出统一到“数据交换中心”；
- 提供标准 CSV 模板、字段校验、编码识别、重复数据处理和逐行错误明细；
- 支持仅校验与正式导入两阶段流程；
- 导出文件可重新导入，减少不同页面各自维护导入导出逻辑的问题。

### 运维诊断与只读降级

- 新增图片来源诊断、病案数据完整性、导出文件中心、权限矩阵和部署就绪检查；
- 数据库迁移、首选图片源、OSS 或临时目录出现关键故障时自动进入只读降级；
- 只读模式阻止业务写入、导入、迁移和新建导出任务，同时保留登录、查询、外部调阅和诊断；
- 管理员可以显式重新检查状态，故障恢复后解除降级。

### OSS 迁移与文件浏览

- OSS 迁移按照“上架号前 4 位 / 上架号-病案号”保存；
- 原图从受控 Nginx 节点读取并上传到 OSS；
- 上架号为空的病案进入等待状态，补齐后再迁移；
- 支持任务创建、批次处理、取消、失败重试、完整性校验和进度统计；
- 新增只读 OSS 与 Nginx 文件浏览器，方便核对目录、对象和图片来源。

### 患者管理与数据治理

- 患者管理支持编辑、导入和条件导出；
- 展示身份证号为空的病案、疑似同一患者的多份病案、年度病案数量和科室分布；
- 导入支持 CSV、XLSX、XLS，处理 UTF-8/GBK 等编码、字段缺失、格式错误和重复数据；
- 大量数据导出采用流式处理，避免一次性加载全部记录。

### 权限与开发者模式

- 图片诊断和导出中心同时要求系统查看与病案读取权限；
- 权限矩阵同时要求角色查看权限，保存快照需要系统管理权限；
- ZIP 与 PDF 导出继续使用 `record:download` 和 `record:pdf:export` 独立权限；
- 开发者模式可以在受控环境中开放兼容 API，但真实患者数据环境应保持关闭。

### 表格操作体验

- 表格操作统一使用图标按钮；
- 页面空间不足或操作数量较多时，将次要操作收纳到“更多”菜单；
- 患者、用户、日志、审计、OSS 迁移、档案装箱等页面统一操作布局。

## 升级前准备

1. 备份 PostgreSQL 数据库；
2. 备份外部配置、密钥、Nginx 配置和当前发布目录；
3. 保留 0.6.3 发布包与当前运行版本清单；
4. 确认数据库账户具备执行 Flyway 迁移和创建索引的权限；
5. 选择业务低峰期执行升级。

## 升级后核对

1. 确认 `/actuator/info`、管理端和发布清单均显示 `0.6.5`；
2. 核对 Flyway 已执行到 `20260723090000`；
3. 验证登录、注册审核、权限和首次改密；
4. 验证病案号、上架号和身份证查询，以及 OSS/本地混合图片读取；
5. 在数据交换中心下载模板并完成一次仅校验导入；
6. 检查患者编辑、身份证缺失和年度/科室统计；
7. 检查 OSS 迁移任务、Nginx/OSS 文件浏览和失败重试；
8. 打开运维诊断中心，核对数据库、Flyway、Nginx、OSS、临时目录与只读状态；
9. 验证 ZIP/PDF 权限、后台任务、Range 下载和下载统计；
10. 校验正式 ZIP 顶层 `SHA256SUMS` 与 `runtime/SHA256SUMS`。
