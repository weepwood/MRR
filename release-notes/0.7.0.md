# MRR 0.7.0 发布说明

发布日期：2026-07-23

## 版本定位

0.7.0 将运维诊断、部署制品和日常管理能力收敛为可正式交付的 Windows 内网版本。前端默认内嵌到后端 JAR，Nginx 继续作为统一入口，并保留外置前端紧急回退。

## 重点更新

- 运维诊断中心新增总览、一键全面体检、处理建议、快捷跳转和运维操作记录；
- 支持管理员主动开启维护只读模式，并与数据库、OSS、图片源和磁盘故障触发的自动降级取并集；
- Vite 正式产物写入 Spring Boot 可执行 JAR，前端、后端、版本和 Git Commit 形成统一制品；
- Windows 管理中心和 `mrrctl.ps1` 支持 `embedded` / `external` 前端模式切换，失败自动恢复；
- 后端 CI 按变更范围执行单元或完整 PostgreSQL 验证，集成测试复用 PostgreSQL 16；
- 表格操作只在空间不足时显示水平省略号菜单，桌面端优先直接显示常用图标。

## 发布前审查修复

- 保留路径根节点 `/api`、`/actuator`、`/swagger-ui`、`/v3/api-docs`、`/api-docs`、`/docs`、`/webjars` 和 `/error` 不再进入 SPA 回退；
- 诊断报告中的账号、客户端 IP、查询参数、原始错误文本、总览中的最近操作和完整性快照异常信息统一脱敏；
- README 的生产部署说明同步为“JAR 内嵌前端 + Nginx 统一入口 + 外置回退”。

## 升级前检查

- 执行数据库、Flyway、Nginx 图片源、OSS、临时目录空间和最近备份检查；
- 确认当前数据库迁移不高于 `20260723090000`，并保留可恢复的 PostgreSQL 备份；
- 备份外部配置、密钥、Nginx 配置与当前完整发布目录；
- 升级后确认前端模式为 `embedded`，并保留 `external` 模式作为紧急回退；
- 使用发布包顶层和运行时目录中的 `SHA256SUMS` 校验全部文件；
- 所有发布门禁必须基于不再发生代码变更的最终候选提交执行。

## 数据库与回滚

- 最低兼容迁移：`20260715113552`；
- 最高兼容迁移：`20260723090000`；
- 本版本不新增 Flyway 迁移；
- 不允许只替换回旧 JAR 或旧前端目录。升级前应备份数据库、外部配置、密钥、Nginx 配置和当前发布目录。
