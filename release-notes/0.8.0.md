# MRR 0.8.0 发布说明

发布日期：2026-07-28

## 版本定位

0.8.0 是影像浏览、OCR/智能分类基础能力和工程运行时的阶段性升级版本。本版本新增影像档案袋全景平铺模式，建立 OCR 与智能分类第一阶段的数据、权限和配置基础，同时将前后端及 GitHub Actions 运行时升级到新的长期维护基线。

## 重点更新

### 影像档案袋全景平铺

- 新增“标准浏览 / 全景平铺”布局切换；
- 图片以规则网格完整展示，不裁剪原图；
- 支持紧凑、舒适、宽松密度和图片宽度设置；
- 首批渲染 60 张，滚动时分批追加，降低大量图片导致的 DOM 压力；
- 支持方向键移动焦点，Enter 或空格选择图片；
- 底部悬浮工具栏继续提供筛选、全选、下载、打印和 PDF 导出；
- 外部 Ticket 调阅模式继续隐藏选择和导出操作；
- 完成 Chrome 86 生产样式兼容处理。

### OCR 与智能分类第一阶段

- 建立统一病案影像类型目录，覆盖 0—15 类型；
- 新增 OCR 文本、词库版本、分类规则版本、分类任务、建议和正式类型变更审计表；
- 新增 OCR 读取、运行、配置，以及分类读取、审核和覆盖权限；
- 系统设置新增 OCR 与智能分类入口；
- OCR 默认关闭，不允许前端配置任意程序路径或命令；
- 后端校验配置名称、布尔值、并发、超时、输出上限和安全阈值；
- 分类建议与正式图片类型分离，不会静默覆盖业务数据。

本阶段尚不包含 OCR 本地执行器、任务调度、规则 CRUD、档案袋智能分类按钮或自动修改正式图片类型。

### 工程与依赖基线

- Node.js 基线升级到 24.15.0，jsdom 升级到 30；
- Vite 升级到 8.1.5，并同步升级 Vue、legacy、mock、归档和开发工具插件；
- Spring Boot 与 MyBatis Spring Boot 升级到 4.1.0；
- iText kernel/layout 升级到 9.7.1；
- 更新 Vue、VueUse、Element Plus、UnoCSS、ESLint、Stylelint、Playwright、AWS SDK、Apache POI 等常规依赖；
- GitHub Actions 运行时升级到 Node 24 兼容版本，包括 setup-node、setup-python、setup-java、pnpm setup、download-artifact 和 GitHub Release Action；
- 继续固定 pnpm 10.33.0、Java 21、PostgreSQL 16 和 Chrome 86 最低生产兼容线。

- 最高兼容迁移：`20260724220200`；

- OCR 与智能分类迁移只新增独立表、索引、默认设置和管理员权限，不删除或改写原业务字段；
