# MRR 1.0.0-rc.1 候选说明

本版本是 V1.0 发布候选，不是正式生产发布或医院启用批准。候选源码身份由实际合并提交及同一轮完整 dry-run 的 run/attempt/manifest 记录；不得将旧版本预演结果作为本候选通过证据。

## 候选范围

- 病案编号精确检索、游标与明确兼容包含查询；三千万合成实验支持精确表达式索引，旧包含 COUNT 存在超时，默认不部署 GIN。真实服务器容量、索引就绪和回滚仍须现场预检。
- 多来源受控影像、Range、正文超时、节点与全局资源许可、半开探针、实际关闭回收；档案导出所有者、下载配额和取消恢复。
- 运维总览索引就绪及容量、NAS/HTTP/Nginx/OSS 节点状态、SDK 池最近采样、进程内有界异常事件及趋势。重启清空，不能替代持续监控或持久审计。
- 身份证查询兼容迁移（#799 已合并 e0ac2036）：患者新增 POST，扫描页普通查询改用 POST 和内存传参，保留旧 GET 和合法旧深链。既有外部 HMAC、Ticket、加密协议及权限不变；旧深链、历史 URL 与定制代理日志仍需现场治理。不得在未经确认时退役调用方。
- 保持既有权限、持久化 Token 撤销、审核及日志边界。注册审核、管理员创建/重置密码、用户与角色管理在事务锁内复核当前操作者、凭据版本及委派权限；账号与角色成功审计与业务变更共同提交，提交后结构化日志继续保留；新增受控内部身份事务账本，不启用实验审计引擎。OCR 分类阶段重新核对授权、事实版本与取消；导出取消领取边界、下载内容摘要、迁移领取与终态确认、Nginx 流释放和响应体超时已完成本地定向修复。OCR、日志新采集、分区切换、GIN 与网关配置继续遵守原审批和现场门禁，不自动开启。

- 本地代码基线 `83a4e280` 累计定向回归：270 项 Java、106 项真实 PostgreSQL 集成测试通过（无失败、错误或跳过）。追加统计有界汇总、分页溢出、条件日期统一及稳定排序、无调用查询收敛和账号列表凭据最小化；未采用实验GIN索引。见[本地候选冻结记录](../docs/backend/local-candidate-freeze-20261128.md)。这不是完整候选制品验收；单 Token 在途撤销、异步执行期授权契约、审计丢失保障及真实部署仍需确认。
