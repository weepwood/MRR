## 文档维护建议

1. 新增功能时，优先在 `docs/guide` 下补充对应说明。
2. 涉及页面调整时，尽量同步补充截图和操作步骤。
3. 发布前执行一次 `npm run docs:build`，确认文档链接和页面都能正常生成。
