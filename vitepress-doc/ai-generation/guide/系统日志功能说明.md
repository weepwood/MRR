# 系统日志功能说明

## 功能概述

系统日志页面已切换为基于 `access_log` 数据库表的真实查询能力，支持分页、组合筛选和详情查看，主要用于排查接口访问问题和异常请求。

## 后端接口

### 查询日志（推荐）

- 接口：`GET /v1/logs-api/search`
- 参数：
  - `page`：页码（默认 `1`）
  - `size`：每页数量（默认 `20`，最大 `200`）
  - `keyword`：关键词，匹配 IP/URI/UA/Query/Body/Referer
  - `clientIp`：客户端 IP（模糊匹配）
  - `requestUri`：请求 URI（模糊匹配）
  - `method`：请求方法（精确匹配，如 `GET`）
  - `responseStatus`：状态码前缀（如 `2`、`4`、`500`）
  - `startTime`：开始时间，格式 `yyyy-MM-dd HH:mm:ss`
  - `endTime`：结束时间，格式 `yyyy-MM-dd HH:mm:ss`

### 兼容接口

- `GET /v2/logs/`
- `GET /v2/logs/ip/{ip}`
- `GET /v2/logs/uri?uri=...`

## 前端页面能力

- 支持筛选项：关键词、IP、URI、方法、状态码、时间范围。
- 表格字段：访问时间、IP、方法、URI、状态码、耗时。
- 展开详情：`User-Agent`、`Query String`、`Referer`、`Request Body`。
- 支持分页查询和一键重置筛选。

## 常见排查场景

### 场景 1：查 5xx 错误

1. 状态码选择 `5xx`。
2. 按时间范围缩小到故障窗口。
3. 展开查看 `requestUri` 与 `requestBody`。

### 场景 2：排查某客户端问题

1. 输入 `clientIp`。
2. 补充 URI 或关键词缩小范围。
3. 按访问时间倒序查看最近请求。

### 场景 3：确认某接口是否被调用

1. 输入 `requestUri` 或关键词。
2. 观察返回总数和最近访问时间。
3. 对比状态码分布判断是否异常。
