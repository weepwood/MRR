# 系统监控功能说明

## 功能概述
系统监控模块提供实时的 JVM 运行时信息监控，包括运行时长、启动参数、类路径等详细信息。

## 后端接口

### 1. 系统运行时信息
- **接口**: `/v1/system/runtime`
- **请求方式**: GET
- **认证**: 需要 Bearer Token
- **响应格式**: 
```json
{
  "code": 200,
  "data": {
    "uptimeMillis": 205917,
    "inputArguments": [
      "-XX:TieredStopAtLevel=1",
      "-Xverify:none",
      "-Dspring.output.ansi.enabled=always",
      "...更多参数"
    ],
    "uptimeFormatted": "3 分钟 25 秒",
    "name": "36660@WEEPWOOD",
    "startTime": 1773840868961,
    "classPath": "C:\\Users\\...\\jre\\lib\\rt.jar;..."
  }
}
```

## 返回字段说明

### 基本信息
- `uptimeMillis`: 系统运行时长（毫秒）
- `uptimeFormatted`: 格式化后的运行时长（如："3 分钟 25 秒"）
- `name`: JVM 进程名称
- `startTime`: 系统启动时间戳（Unix 毫秒）

### JVM 参数
- `inputArguments`: JVM 启动参数数组
  - 包含所有 -X、-D、-XX 等参数
  - 显示 JVM 配置和调优选项

### 类路径
- `classPath`: Java 类路径
  - 包含所有 JAR 文件路径
  - 包含编译后的 classes 路径
  - 使用分号 `;` 分隔（Windows）或冒号 `:`（Linux/Mac）

### 1. 顶部信息卡片 - 并排显示
- ⏱️ **运行时长** - 显示格式化后的系统运行时间（紫色主题）
- 💻 **JVM 名称** - 显示 JVM 进程信息（粉色主题）
- 📅 **启动时间** - 显示系统启动的日期时间（绿色主题）
- ✅ **系统健康状态** - 显示系统状态和端口（橙色/绿色主题，带脉冲动画）

**布局特性：**
- 📐 **网格布局** - 使用 CSS Grid 实现响应式并排
- 🔄 **自动换行** - 桌面端 4 列并排，移动端单列堆叠
- 🎨 **顶部色条** - 每个卡片顶部有 4px 彩色线条区分类型
- 🔵 **图标容器** - 柔和的半透明背景 + 对应主题色图标
- ✨ **悬浮动画** - 卡片上移 4px + 阴影增强
- 📱 **响应式** - 最小宽度 260px，自动适配屏幕

### 2. JVM 启动参数列表
- 📋 列出所有启动参数
- 编号显示，便于引用
- 支持滚动查看
- 悬停高亮效果
- 显示参数总数标签

### 3. 系统属性信息
- 💻 **操作系统** - OS 名称和版本
- 🔧 **CPU 架构** - 处理器架构类型
- ☕ **Java 版本** - JDK/JRE 版本号
- 🏢 **Java 供应商** - Java 发行厂商
- 📄 **文件编码** - 默认字符集编码
- 👤 **用户名称** - 当前系统用户
- 📁 **用户目录** - 用户主目录路径
- 💼 **工作目录** - 应用运行目录
- 🔗 **Java 主目录** - Java 安装路径

采用网格布局响应式展示，每个属性卡片带图标和颜色区分。

### 4. 内存使用情况
- 📊 **总使用率** - 大号字体醒目显示，根据使用率显示不同颜色（正常绿色、警告橙色、严重红色）
- 📦 **堆内存详情** - 初始大小、已提交、最大值、已使用量
- 💾 **非堆内存详情** - 初始大小、已提交、最大值、已使用量

### 5. 内存使用趋势图表
- 📈 **SVG 折线图** - 专业矢量图形，清晰展示内存变化趋势
- 🎨 **三色折线**: 
  - 💜 紫色渐变线（堆内存使用量）
  - 💗 粉色渐变线（非堆内存使用量）
  - 💙 蓝色渐变线（使用率百分比）
- ⚡ **绘制动画** - 折线从左到右平滑绘制效果
- ✨ **数据点** - 圆点标记 + 悬停放大效果
- 🖱️ **交互提示** - 鼠标悬停显示精确数值和时间
- 📊 **网格参考** - 虚线网格便于读取数值
- 📱 **响应式** - 移动端自动调整高度和字体

### 6. 系统健康状态
- ✅ **状态指示** - UP（绿色）/ DOWN（红色），带脉冲动画效果
- 🔌 **端口信息** - 显示服务端口号
- 🫀 **组件健康** - 各组件（如内存）的健康状态

### 7. 系统详细信息
- 📋 **JVM 信息** - 应用名称、启动时间、运行时长、Java 版本、供应商、主目录
- 💽 **内存信息** - 已用内存、总内存、最大内存、空闲内存

``javascript

// 获取系统运行时信息

```

### 在 router 中配置
``javascript
{
  path: '/admin/monitoring',
  name: 'Monitoring',
  component: () => import('@/components/admin/MonitoringView.vue'),
  meta: { requiresAuth: true }

```

## 7. 使用说明

### 访问监控页面
1. 登录系统
2. 进入后台管理界面
3. 点击"系统监控"菜单
4. 查看实时运行信息

### 刷新数据
- 点击右上角"刷新"按钮
- 重新获取最新系统信息

### 查看参数详情
- 滚动 JVM 参数列表查看所有参数
- 鼠标悬停查看完整类路径
- 点击文本域可选择复制内容

## 8. 注意事项

1. **权限要求**: 需要管理员权限访问
2. **数据敏感性**: 类路径包含系统信息，注意保密
3. **性能影响**: 频繁刷新可能增加服务器负载
4. **跨平台差异**: 路径分隔符在不同系统上可能不同
