## 技术架构

### 前端架构

**技术栈**
- **框架**: Vue 3 (Composition API)
- **语言**: TypeScript
- **构建工具**: Vite
- **UI 组件**: Element Plus / Fantastic Admin
- **状态管理**: Pinia
- **路由**: Vue Router
- **HTTP 客户端**: Axios

**目录结构**
```
frontend-fantastic-admin/
├── src/
│   ├── api/              # API 接口定义
│   ├── components/       # 公共组件
│   ├── layouts/          # 布局组件
│   ├── router/           # 路由配置
│   ├── store/            # 状态管理
│   ├── types/            # TypeScript 类型定义
│   ├── ui/               # UI 组件库
│   └── utils/            # 工具函数
├── public/               # 静态资源
└── package.json
```

**核心模块**
- **认证模块**: 登录、注册、密码重置
- **病案管理**: 患者信息、扫描记录
- **影像浏览**: DICOM 影像查看
- **统计分析**: 数据统计、图表展示
- **系统管理**: 用户管理、权限控制

### 后端架构

**技术栈**
- **框架**: Spring Boot 4.x
- **ORM**: MyBatis
- **数据库**: PostgreSQL 15+
- **认证**: JWT
- **API 文档**: SpringDoc (Swagger)
- **监控**: Spring Actuator

**分层架构**
```
┌─────────────────────────────────┐
│      Controller Layer           │  接收请求、参数验证、响应封装
├─────────────────────────────────┤
│       Service Layer             │  业务逻辑、事务管理
├─────────────────────────────────┤
│        Mapper Layer             │  数据访问、SQL 映射
├─────────────────────────────────┤
│       Entity/DTO Layer          │  数据模型、数据传输对象
└─────────────────────────────────┘
```

**核心组件**
- **拦截器**: 登录验证、权限检查、日志记录
- **异常处理**: 全局异常处理器
- **安全配置**: JWT 认证、密码加密
- **定时任务**: 日志清理、临时文件清理

### 数据库架构

**Schema 设计**
- **app**: 应用数据 (默认 schema)
- **public**: PostgreSQL 默认 schema

**核心表结构**

| 表名 | 说明 | 主要字段 |
|------|------|----------|
| `mr_patient` | 患者信息 | patient_id, name, gender, birth_date |
| `mr_scan` | 扫描记录 | scan_id, patient_id, scan_date, modality |
| `mr_statistics` | 统计数据 | stat_id, date, count, type |
| `mr_auth_user` | 用户账号 | user_id, username, password_hash |
| `mr_auth_role` | 角色定义 | role_id, role_name, permissions |
| `mr_log` | 操作日志 | log_id, user_id, action, timestamp |

**索引策略**
- 主键索引: 所有表的主键
- 外键索引: 关联字段
- 查询索引: 常用查询条件字段
- 复合索引: 多字段组合查询

## 系统特性

### 安全特性

**认证机制**
- JWT Token 认证
- Token 刷新机制
- 密码加密存储 (BCrypt)

**权限控制**
- 基于角色的访问控制 (RBAC)
- 细粒度权限注解
- 接口级权限拦截

**数据安全**
- AES 加密敏感数据
- SQL 注入防护
- XSS 攻击防护
- CSRF 防护

### 性能特性

**前端优化**
- 路由懒加载
- 组件按需加载
- 图片懒加载
- 代码分割

**后端优化**
- 数据库连接池
- SQL 查询优化
- 批量操作支持
- 缓存机制 (可选 Redis)

### 可扩展性

**水平扩展**
- 无状态设计
- 负载均衡支持
- 数据库读写分离 (可选)

**垂直扩展**
- 模块化设计
- 插件式架构
- 配置化功能
