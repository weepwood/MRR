# 系统管理

系统管理包含用户、角色权限和系统设置。不同页面需要不同权限，菜单不可见通常表示当前账号没有访问权限。

## 用户管理

进入“系统 → 用户管理”，需要 `user:manage` 权限。页面用于：

- 查询和查看用户；
- 创建由管理员分配的系统账号；
- 修改显示名称、角色和启停状态；
- 重置其他用户的登录密码；
- 查看首次登录、密码重置和临时密码过期状态。

登录页不开放自助注册和在线找回密码。新账号、角色调整和密码重置均由系统管理员完成。

### 创建用户

点击页面右上角“创建用户”，填写用户名、显示名称、角色、初始状态和临时密码有效期。系统默认生成 16 位一次性临时密码，有效期默认 24 小时。

创建成功后：

1. 临时密码只在结果窗口显示一次；
2. 管理员需要通过安全方式把账号和临时密码交付给用户；
3. 用户第一次登录只能进入“修改初始密码”页面；
4. 完成改密前，病案、患者、统计和系统管理接口均不可访问；
5. 修改成功后当前 Token 立即失效，用户必须使用新密码重新登录。

关闭临时密码结果窗口前，需要确认已经安全保存或交付凭据。系统不会在数据库、日志或后续查询接口中返回明文临时密码。

### 管理员重置密码

在用户行操作中点击“重置密码”。为避免管理员会话被他人借用，重置时必须再次输入当前管理员密码。

重置成功后：

- 系统重新生成一次性临时密码；
- 目标用户已有 JWT 因密码版本变化立即失效；
- 目标用户下次登录必须修改密码；
- 已禁用账号需要先启用后才能重置；
- 管理员不能通过该入口重置自己的密码，应使用个人修改密码功能；
- 不能禁用或降级系统中最后一个有效管理员。

### 凭据状态

| 状态 | 含义 |
| --- | --- |
| 正常 | 已完成密码设置，可以正常登录 |
| 待修改初始密码 | 新创建用户尚未完成首次改密 |
| 密码已重置 | 管理员重置后尚未完成改密 |
| 临时密码已过期 | 需要管理员重新生成临时密码 |
| 已禁用 | 账号无法登录 |

密码策略当前为 12–64 位。建议使用由多个无关词语组成的长口令，不要继续使用管理员分配的临时密码。

## 权限管理

进入“系统 → 权限管理”，需要 `role:read` 等权限。

| 权限 | 主要页面 |
| --- | --- |
| `record:read` | 记录、患者、装箱、OSS 迁移、影像档案袋 |
| `record:manage` | 记录修改等高影响操作 |
| `statistics:read` | 统计分析、统计明细、病案统计 |
| `user:manage` | 用户创建、编辑、禁用和密码重置 |
| `role:read` | 权限管理 |
| `log:read` | 日志管理、图片访问审计 |
| `system:read` | 系统设置、系统监控、服务状态、接口分析、内部文档和 API 文档 |

前端菜单权限不替代后端权限校验。不要只根据菜单名称推断角色能力。

## 系统设置

进入“系统 → 系统设置”，需要 `system:read` 权限。设置页只保留已有实际消费方的配置，不展示数据库连接、SMTP、备份、JWT、AES 或 OSS 密钥等占位项。

### 系统标识

- 系统名称：保存后更新浏览器标题等显示。

### 图片来源

影像档案袋支持：

| 选项 | 行为 |
| --- | --- |
| 本地图片 `local` | 默认，使用本地或 NAS 图片地址 |
| OSS 图片 `oss` | 已迁移记录生成签名 URL，失败时回退本地 |

注意：

- 未保存、设置非法或读取失败时回退 `local`。
- OSS 模式只对存在 `oss_url` 的记录生成签名地址。
- 服务端 ZIP 下载当前仍从本地存储读取。
- 切换图片来源后应抽样检查普通病案、高位病案号和未迁移图片。

### 影像档案袋浏览

- 默认影像栏模式：缩略图或列表。
- 默认预览模式：单页或连续滚动。
- 缩略图目标宽度。
- 首批影像渲染数量。
- 图片是否自动适应预览区域。
- 是否按病案号和上架号记住选中图片。

### 访问水印

- 水印显示开关。
- 水印透明度。

设置保存后，已打开的档案袋会实时增加、移除或刷新水印。

### 开发者模式

“开发者模式”用于隔离开发环境、接口联调和旧客户端过渡，默认关闭。

启用并保存后立即生效，无需重启后端：

- 无 Bearer Token、无效 Token 或过期 Token 的普通受保护 API 会使用虚拟 `dev / ADMIN` 会话；
- 有效 JWT 始终优先使用真实用户，不会被替换；
- API 跨域策略临时允许任意 Origin，恢复旧开发阶段的调用方式；
- 兼容调用的响应包含 `X-MRR-Developer-Mode: enabled`；
- 后端为每次认证绕过写入警告日志；
- 外部影像 Ticket 接口仍需 HMAC、时间戳、nonce 和来源 IP 校验。

启用后，所有使用后台主布局的页面顶部都会显示不可关闭的“开发者模式已启用”安全警告。关闭开发者模式并保存后，警告自动消失。

开发者模式的虚拟管理员会话不参与首次登录强制改密。生产环境、可被非开发网络访问的环境以及真实患者数据环境不应启用。

### 页面外观

- 页面标题风格：页面同级或 Hero 卡片。
- 全局圆角系数。
- 主题等框架外观设置。

登录页与后台页面使用同一套表面、边框、圆角、控件和深色模式变量。

## 设置保存规则

设置加载顺序：

1. 优先读取服务端 `mr_system_settings`。
2. 服务端不可用时回退当前浏览器本地配置。
3. 服务端字符串值恢复为 boolean、number 或枚举。
4. 数值越界时限制到允许范围，非法枚举回退默认值。
5. 保存后通过浏览器事件通知已打开页面刷新配置。
6. 开发者模式只有服务端保存成功才会改变。

设置页会显示配置来源、最近同步时间和未保存状态。排查异常时同时检查服务端设置和浏览器 `localStorage`。

## 帮助与文档

进入“帮助 → 帮助与文档”，可打开：

- 用户手册：已登录账号。
- 内部文档：管理员或 `system:read`。
- 实时 API 文档：管理员或 `system:read`。

系统会签发短期 HttpOnly 文档访问 Cookie。用户手册与内部文档分别构建，用户手册搜索不会包含内部资料。

## 管理注意事项

- 不要在页面设置中保存数据库密码、JWT、AES 或 OSS 密钥。
- 不要通过聊天工具、公开邮件或日志发送临时密码。
- 正式环境必须修改默认账号密码。
- 修改角色后验证菜单、路由和接口三层结果。
- 开发者模式只能用于受控联调，生产环境必须关闭。
- 切换图片来源前确认本地和 OSS 均有可靠回退方案。
- 批量数据修复、迁移和装箱更新应先备份并在副本验证。
