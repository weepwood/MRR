# 系统管理

## 用户管理

### 查看用户列表

显示所有系统用户，包含：用户名、姓名、角色、状态、最后登录时间。

### 新增用户

1. 点击"新增用户"按钮
2. 填写用户信息：
   - 用户名（登录使用）
   - 姓名（显示名称）
   - 密码（符合密码策略）
   - 角色（分配角色）
   - 状态（启用/禁用）
3. 点击"保存"

### 编辑用户

- 修改用户基本信息
- 重置密码
- 启用/禁用用户

### 删除用户

- 不可删除超级管理员
- 删除前需确认

## 角色管理

### 预设角色

| 角色 | 权限范围 |
|------|----------|
| 超级管理员 | 所有权限 |
| 管理员 | 用户管理、数据管理、统计分析 |
| 操作员 | 病案录入、查看、编辑 |
| 查看者 | 仅查看权限 |

### 自定义角色

1. 点击"新增角色"
2. 设置角色名称
3. 勾选权限列表
4. 保存

### 权限粒度

系统权限按模块和操作划分：

```
病案管理: 查看 / 新增 / 编辑 / 删除
影像管理: 查看 / 上传 / 下载 / 删除
统计分析: 查看 / 导出
系统管理: 用户管理 / 角色管理 / 系统设置
日志管理: 查看 / 导出
```

## 系统设置

### 基本设置

- 系统名称
- Logo
- 页脚信息

### 安全设置

- 密码策略（长度、复杂度）
- 登录失败锁定阈值
- Session 超时时间
- Token 有效期

### 存储设置

- 影像存储路径
- OSS 配置（可选）
- 文件大小限制

## 操作日志

### 日志查询

- 按用户查询
- 按操作类型查询
- 按时间范围查询
- 按目标资源查询

### 日志详情

每条日志包含：
- 操作时间
- 操作用户
- 操作类型（新增/修改/删除/查看）
- 操作对象
- 操作详情
- IP 地址

### 日志导出

- 支持导出为 Excel/CSV
- 支持自定义导出时间范围
- 支持筛选后导出
