# 系统管理

系统管理包含用户、角色权限和系统设置。不同页面需要不同权限，菜单不可见通常表示当前账号没有访问权限。

## 用户管理

进入“系统 → 用户管理”，需要 `user:manage` 权限。页面通常用于：

- 查询和查看用户。
- 新增或编辑用户信息。
- 分配角色。
- 启用或禁用账号。
- 重置或修改账号凭据。

账号状态和角色修改会立即影响菜单与接口访问。保存前核对目标账号，修改后使用目标角色账号验证。

登录页不开放自助注册和验证码重置。新账号、角色调整和密码重置由系统管理员在用户管理中完成。

## 权限管理

进入“系统 → 权限管理”，需要 `role:read` 等权限。

| 权限 | 主要页面 |
| --- | --- |
| `record:read` | 记录、患者、装箱、OSS 迁移、影像档案袋 |
| `record:manage` | 记录修改等高影响操作 |
| `statistics:read` | 统计分析、统计明细、病案统计 |
| `user:manage` | 用户管理 |
| `role:read` | 权限管理 |
| `log:read` | 日志管理、图片访问审计 |
| `system:read` | 系统设置、系统监控、服务状态、接口分析、内部文档和 API 文档 |

前端菜单权限不替代后端权限校验。不要只根据菜单名称推断角色能力。

## 系统设置

进入“系统 → 系统设置”，需要 `system:read` 权限。设置页只保留已有实际消费方的配置，不展示数据库连接、SMTP、备份、JWT、AES 或 OSS 密钥等占位项。

### 系统标识

- 系统名称：保存后更新浏览器标题等显示。

### 图片来源

影像档案袋支持：

| 选项 | 行为 |
| --- | --- |
| 本地图片 `local` | 默认，使用本地或 NAS 图片地址 |
| OSS 图片 `oss` | 已迁移记录生成签名 URL，失败时回退本地 |

注意：

- 未保存、设置非法或读取失败时回退 `local`。
- OSS 模式只对存在 `oss_url` 的记录生成签名地址。
- 服务端 ZIP 下载当前仍从本地存储读取。
- 切换图片来源后应抽样检查普通病案、高位病案号和未迁移图片。

### 影像档案袋浏览

- 默认影像栏模式：缩略图或列表。
- 默认预览模式：单页或连续滚动。
- 缩略图目标宽度。
- 首批影像渲染数量。
- 图片是否自动适应预览区域。
- 是否按病案号和上架号记住选中图片。

### 访问水印

- 水印显示开关。
- 水印透明度。

设置保存后，已打开的档案袋会实时增加、移除或刷新水印。

### 开发者模式

“开发者模式”用于隔离开发环境、接口联调和旧客户端过渡，默认关闭。

启用并保存后立即生效，无需重启后端：

- 无 Bearer Token、无效 Token 或过期 Token 的普通受保护 API 会使用虚拟 `dev / ADMIN` 会话；
- 有效 JWT 始终优先使用真实用户，不会被替换；
- API 跨域策略临时允许任意 Origin，恢复旧开发阶段的调用方式；
- 兼容调用的响应包含 `X-MRR-Developer-Mode: enabled`；
- 后端为每次认证绕过写入警告日志；
- 外部影像 Ticket 接口仍需 HMAC、时间戳、nonce 和来源 IP 校验。

启用后，所有使用后台主布局的页面顶部都会显示不可关闭的“开发者模式已启用”安全警告。警告会提示虚拟管理员与宽松跨域风险，并提供打开系统设置的入口；页面会在设置保存、重新聚焦浏览器以及每 30 秒定时检查时同步后端状态。关闭开发者模式并保存后，警告自动消失。

启用开发者模式需要二次确认。生产环境、可被非开发网络访问的环境以及真实患者数据环境不应启用。完成联调后应立即关闭，并用无 Token 请求确认重新返回 `401`。

### 页面外观

- 页面标题风格：页面同级或 Hero 卡片。
- 全局圆角系数。
- 主题等框架外观设置。

登录页与后台页面使用同一套表面、边框、圆角、控件和深色模式变量，不再使用独立的硬编码配色。

## 设置保存规则

设置加载顺序：

1. 优先读取服务端 `mr_system_settings`。
2. 服务端不可用时回退当前浏览器本地配置。
3. 服务端字符串值恢复为 boolean、number 或枚举。
4. 数值越界时限制到允许范围，非法枚举回退默认值。
5. 保存后通过浏览器事件通知已打开页面刷新配置。
6. 开发者模式只有服务端保存成功才会改变；保存失败不会仅在浏览器本地伪装为启用。

设置页会显示配置来源、最近同步时间和未保存状态。排查异常时同时检查服务端设置和浏览器 `localStorage`。

## 帮助与文档

进入“帮助 → 帮助与文档”，可打开：

- 用户手册：已登录账号。
- 内部文档：管理员或 `system:read`。
- 实时 API 文档：管理员或 `system:read`。

系统会签发短期 HttpOnly 文档访问 Cookie。用户手册与内部文档分别构建，用户手册搜索不会包含内部资料。

## 管理注意事项

- 不要在页面设置中保存数据库密码、JWT、AES 或 OSS 密钥。
- 正式环境必须修改默认账号密码。
- 修改角色后验证菜单、路由和接口三层结果。
- 开发者模式只能用于受控联调，生产环境必须关闭。
- 切换图片来源前确认本地和 OSS 均有可靠回退方案。
- 批量数据修复、迁移和装箱更新应先备份并在副本验证。
