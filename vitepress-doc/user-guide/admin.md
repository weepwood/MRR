# 系统管理

系统管理包含用户管理、权限管理和系统设置。不同页面需要不同权限，菜单不可见通常表示当前账号没有访问权限。

## 用户管理

进入“系统 → 用户管理”，需要 `user:manage` 权限。

页面用于维护系统账号和账号状态。可执行操作以当前页面按钮为准，通常包括：

- 查看和查询用户
- 新增或编辑用户信息
- 分配角色
- 启用或禁用账号
- 重置或修改账号凭据

涉及账号状态和角色的修改会直接影响该用户能够访问的菜单与接口，保存前应核对目标账号和角色范围。

## 权限管理

进入“系统 → 权限管理”，需要 `role:read` 等角色权限。

MRR 使用基于角色的访问控制。当前路由中常见权限包括：

| 权限 | 主要页面 |
| --- | --- |
| `record:read` | 记录、患者、档案装箱、OSS 迁移、影像档案袋 |
| `statistics:read` | 统计分析、统计明细、病案统计 |
| `user:manage` | 用户管理 |
| `role:read` | 权限管理 |
| `log:read` | 日志管理、图片访问审计 |
| `system:read` | 系统设置、系统监控、服务状态、接口响应分析、内部文档和 API 文档 |

管理员角色可能拥有更广泛权限。不要仅根据菜单名称推断权限，应以当前角色权限集合和后端校验结果为准。

## 系统设置

进入“系统 → 系统设置”，需要 `system:read` 权限。

当前设置页只保留已有明确消费方、保存后能真实影响功能的配置，不展示尚未接入业务逻辑的 SMTP、备份、安全策略或数据库连接等占位项。

### 系统标识

- **系统名称**：保存后更新浏览器标签页标题。

### 影像档案袋浏览

- 默认影像栏模式：缩略图或列表
- 默认预览模式：单页或连续滚动
- 缩略图目标宽度
- 首批影像渲染数量
- 图片是否自动适应预览区域
- 是否按病案号和上架号记住选中图片

### 访问水印

- 水印显示开关
- 水印透明度

设置保存后，当前已打开的影像档案袋会实时增加、移除或刷新水印。

### 页面外观

- 页面标题风格：页面同级或 Hero 卡片
- 全局圆角系数：业务卡片和常用 Element Plus 控件同步调整
- 主题等框架外观设置

页面标题无论选择哪种容器，都保持英文标题、中文标题和页面说明三行结构。

## 设置保存规则

设置加载顺序：

1. 优先读取服务端 `mr_system_settings`。
2. 服务端不可用时回退当前浏览器本地配置。
3. 服务端字符串值会恢复为 boolean、number 或枚举。
4. 数值超出允许范围时会被限制，非法枚举回退默认值。
5. 保存后通过浏览器事件通知已打开业务页面刷新配置。

设置页同时显示配置来源、最近同步时间和未保存状态。保存前应确认当前读取的是服务器配置还是本地回退值。

## 帮助与文档

进入“帮助 → 帮助与文档”。

可打开：

- 用户手册：已登录账号
- 内部文档：管理员或 `system:read`
- 实时 API 文档：管理员或 `system:read`

系统会先向后端申请 30 分钟有效的 HttpOnly 文档访问 Cookie，再打开对应同域地址。用户手册与内部文档分别构建，用户手册的本地搜索索引不会包含内部文档。

## 管理注意事项

- 不要在页面设置中保存数据库密码、JWT 密钥、AES 密钥或 OSS 密钥；这些值必须由部署环境提供。
- 调整角色权限后，应使用目标角色账号验证菜单、路由和接口三层访问结果。
- 生产环境不要继续使用仓库默认账号密码。
- 历史浏览器本地设置可能被自动迁移；排查异常时同时检查服务端配置和 localStorage。
