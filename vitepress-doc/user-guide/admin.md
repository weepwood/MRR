# 系统管理

系统管理包含用户、注册审核、角色权限和系统设置。菜单不可见通常表示当前账号没有对应权限，或管理员在菜单设置中隐藏了该入口。

## 用户管理

进入“系统 → 用户管理”，需要 `user:manage` 权限。页面用于：

- 查询、分页和筛选用户；
- 审核用户自助注册申请；
- 由管理员直接创建账号；
- 修改显示名称、角色和账号状态；
- 重置其他用户密码；
- 查看申请、审核、首次改密和临时密码状态。

## 注册申请审核

用户可以在登录页提交注册申请。新申请状态为 `pending`，审核前不能登录。

管理员可以：

1. 查看用户名、显示名称、联系方式、申请说明和申请时间；
2. 批准申请并选择最终角色；
3. 拒绝申请并填写拒绝原因；
4. 按状态筛选待审核、已启用、已拒绝和已停用用户。

审核操作会记录审核人、时间和安全审计日志。多个管理员同时处理同一申请时，后提交的一方可能收到“状态已发生变化”，应刷新后重新判断。

详细流程见 [账号、注册与登录](./accounts.md)。

## 管理员创建用户

点击“创建用户”，填写用户名、显示名称、角色和临时密码有效期。系统生成 16 位一次性临时密码，新账号以启用状态创建。

创建成功后：

1. 临时密码只显示一次；
2. 管理员通过安全渠道交付凭据；
3. 用户第一次登录只能进入首次改密流程；
4. 完成改密前，普通业务接口不可访问；
5. 改密后旧 Token 立即失效，用户需要重新登录。

不应在聊天工具、普通邮件、截图或日志中发送临时密码。

## 管理员重置密码

在用户行操作中点击“重置密码”。重置时必须再次输入当前管理员密码。

重置成功后：

- 系统重新生成一次性临时密码；
- 目标用户已有 Token 立即失效；
- 目标用户下次登录必须改密；
- 只有启用账号可以重置；
- 管理员不能通过该入口重置自己的密码；
- 系统中最后一个有效管理员不能被禁用或降级。

## 账号状态

| 状态 | 含义 | 可否登录 |
| --- | --- | --- |
| `pending` | 注册申请等待审核 | 否 |
| `active` | 已启用 | 是 |
| `rejected` | 注册申请被拒绝 | 否 |
| `disabled` | 已停用 | 否 |

普通密码长度当前为 **6～64 位**。建议实际使用不少于 12 位的长口令。

## 权限管理

进入“系统 → 权限管理”，需要 `role:read`；修改角色通常需要更高的角色管理权限。

### 记录类权限

| 权限 | 能力 |
| --- | --- |
| `record:read` | 查看记录、患者、档案装箱、影像、OSS/Nginx 文件和迁移页面 |
| `record:edit` | 修改图片类型等编辑操作，并包含读取 |
| `record:download` | 生成和下载 ZIP，并包含读取 |
| `record:pdf:export` | 生成和下载 PDF，并包含读取 |
| `record:manage` | 包含读取、编辑、下载和 PDF 导出 |

### 其他权限

| 权限 | 主要能力 |
| --- | --- |
| `statistics:read` | 病案扫描统计、统计明细 |
| `user:manage` | 用户创建、注册审核、编辑、停用和密码重置 |
| `role:read` | 查看权限和角色 |
| `role:manage` | 管理角色，并包含 `role:read` |
| `log:read` | 日志管理、图片访问审计 |
| `system:read` | 系统设置、数据关系、监控、接口分析、内部文档和 API 文档 |

前端菜单、路由守卫和后端接口都会校验权限。隐藏按钮不是安全措施，后端权限才是最终边界。

## 系统设置

进入“系统 → 系统设置”，需要 `system:read`。设置页统一管理系统信息、登录支持、档案浏览、访问安全、开发者模式、菜单显示、科室配色和界面外观。

### 系统信息

可配置：

- 系统名称、简称和英文名称；
- 所属机构；
- 系统简介；
- 登录页环境标签和说明；
- 支持团队、电话、邮箱、服务时间和补充说明。

管理员联系信息默认不公开。只有同时启用联系信息并允许登录页公开显示，匿名配置接口才会返回相应内容。

### 图片来源与档案浏览

| 选项 | 行为 |
| --- | --- |
| 本地图片 `local` | 使用 Nginx/NAS/HTTP/本地目录读取 |
| OSS 图片 `oss` | 优先读取已迁移 OSS 图片，失败时降级到非 OSS 来源 |

单份病案可以混合 OSS 与非 OSS 图片。后端逐张解析，不要求整份病案一次性迁移完成。

档案浏览还可以配置：

- 默认缩略图或列表；
- 单页或连续滚动；
- 缩略图目标宽度；
- 首批渲染数量；
- 自动适应预览区域；
- 是否记住当前病案的选中图片；
- 水印和身份证完整显示/复制策略。

### 菜单显示

管理员可以控制部分菜单是否显示。菜单隐藏仅影响界面，不撤销用户已有权限，也不替代后端校验。需要真正禁止访问时，应修改角色权限。

### 访问安全

可配置：

- 水印显示和透明度；
- 身份证完整显示和复制；
- 每日 IP 切换限制；
- 是否关闭 IP 访问限制（仅限明确的受控环境）。

涉及真实患者数据时，不建议关闭访问限制。

### 开发者模式

开发者模式用于受控开发和旧客户端联调，默认关闭。启用后普通受保护 API 可以使用虚拟管理员会话回退，并放宽 API 跨域；有效 JWT 始终优先使用真实用户。

开发者模式不会取消外部影像 Ticket 的 HMAC、时间戳、nonce 和来源 IP 校验，也不应成为凭据管理后门。

生产环境、真实患者数据环境和可被非开发网络访问的环境必须关闭开发者模式。

### 页面外观

可配置：

- 页面标题容器；
- 全局圆角；
- 主题和导航外观；
- 管理概览卡片的显示、大小、顺序、置顶和颜色。

## 登录与会话安全

- 用户名或密码错误返回统一提示；
- 登录失败过多会触发限流；
- 用户退出时后端撤销当前 Token，前端再清理会话；
- 密码修改、重置和首次改密会增加密码版本，使旧 Token 失效；
- 服务端异常不把内部堆栈返回浏览器；
- Token 黑名单当前依赖后端进程内存，服务重启后撤销记录会丢失，仍需依赖 Token 有效期和密码版本。

## 设置保存规则

1. 优先读取服务端 `mr_system_settings`；
2. 服务端不可用时，部分界面设置可回退浏览器本地配置；
3. 服务端字符串会恢复为 boolean、number 或枚举；
4. 数值越界时限制到允许范围；
5. 保存后通知已打开页面刷新；
6. 开发者模式只有服务端保存成功才会改变。

排查设置异常时检查配置来源、最近同步时间、未保存状态和浏览器 `localStorage`。

## 管理注意事项

- 不要在页面设置中保存数据库密码、JWT、AES、HMAC 或 OSS 密钥；
- 正式环境必须修改初始管理员密码；
- 修改角色后验证菜单、路由和接口三层结果；
- 下载和 PDF 权限应按岗位最小化授权；
- 开发者模式只能用于受控联调；
- 切换图片来源前抽样检查已迁移、未迁移和混合来源病案；
- 批量导入、迁移和装箱更新应先备份并在副本验证。
