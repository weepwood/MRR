# 系统管理

系统管理包含用户、注册审核、角色权限和系统设置。菜单不可见通常表示当前账号没有对应权限，或管理员在菜单设置中隐藏了该入口。

## 用户管理

进入“系统 → 用户管理”，需要 `user:manage` 权限。页面用于：

- 查询、分页和筛选用户；
- 审核用户自助注册申请；
- 由管理员直接创建账号；
- 修改显示名称、角色和账号状态；
- 重置其他用户密码；
- 查看申请、审核、首次改密和临时密码状态。

## 注册申请审核

用户可以在登录页提交注册申请。新申请状态为 `pending`，审核前不能登录。

管理员可以：

1. 查看用户名、显示名称、联系方式、申请说明和申请时间；
2. 批准申请并选择最终角色；
3. 拒绝申请并填写拒绝原因；
4. 按状态筛选待审核、已启用、已拒绝和已停用用户。

审核操作会记录审核人、时间和安全审计日志。多个管理员同时处理同一申请时，后提交的一方可能收到“状态已发生变化”，应刷新后重新判断。

详细流程见 [账号、注册与登录](./accounts.md)。

## 管理员创建用户

点击“创建用户”，填写用户名、显示名称、角色和临时密码有效期。系统生成 16 位一次性临时密码，新账号以启用状态创建。

创建成功后：

1. 临时密码只显示一次；
2. 管理员通过安全渠道交付凭据；
3. 用户第一次登录只能进入首次改密流程；
4. 完成改密前，普通业务接口不可访问；
5. 改密后旧 Token 立即失效，用户需要重新登录。

不应在聊天工具、普通邮件、截图或日志中发送临时密码。

## 管理员重置密码

在用户行操作中点击“重置密码”。重置时必须再次输入当前管理员密码。

重置成功后：

- 系统重新生成一次性临时密码；
- 目标用户已有 Token 立即失效；
- 目标用户下次登录必须改密；
- 只有启用账号可以重置；
- 管理员不能通过该入口重置自己的密码；
- 系统中最后一个有效管理员不能被禁用或降级。

## 账号状态

| 状态 | 含义 | 可否登录 |
| --- | --- | --- |
| `pending` | 注册申请等待审核 | 否 |
| `active` | 已启用 | 是 |
| `rejected` | 注册申请被拒绝 | 否 |
| `disabled` | 已停用 | 否 |

普通密码长度当前为 **6～64 位**。建议实际使用不少于 12 位的长口令。

## 权限管理

进入“系统 → 权限管理”，需要 `role:read`；修改角色通常需要更高的角色管理权限。

### 记录类权限

| 权限 | 当前主分支能力 |
| --- | --- |
| `record:read` | 查看记录、患者、档案装箱、影像、OSS/Nginx 文件和迁移页面；图片类型修改接口当前也继承此权限 |
| `record:edit` | 已定义的记录编辑权限，并包含读取；当前主分支尚未覆盖全部写接口 |
| `record:download` | 生成和下载 ZIP，并包含读取 |
| `record:pdf:export` | 生成和下载 PDF，并包含读取 |
| `record:manage` | 包含读取、编辑、下载和 PDF 导出 |

不能仅根据权限名称推断某个接口的实际边界。具体接口以当前后端 Controller、自动化测试、运维诊断中心权限矩阵和运行中的 OpenAPI 为准。

### 其他权限

| 权限 | 主要能力 |
| --- | --- |
| `statistics:read` | 病案扫描统计、统计明细 |
| `user:manage` | 用户创建、注册审核、编辑、停用和密码重置 |
| `role:read` | 查看权限和角色 |
| `role:manage` | 管理角色，并包含 `role:read` |
| `log:read` | 日志管理、图片访问审计 |
| `system:read` | 系统设置、数据关系、运维诊断、监控、接口分析、内部文档和 API 文档 |
| `system:error:read` | 查看运行错误中心、错误详情和基础脱敏堆栈 |
| `system:error:manage` | 修改运行错误处理状态，并包含 `system:error:read` |

前端菜单、路由守卫和后端接口都会校验权限。隐藏按钮不是安全措施，后端权限才是最终边界。

### 权限矩阵与版本快照

进入“运维 → 运维诊断中心 → 权限矩阵”，需要 `system:read`。页面根据当前接口和角色计算实际访问结果，可按接口、操作或权限搜索，并保存带名称的版本快照与上一版本比较。

建议在正式升级、批量调整角色、新增管理接口或外部接口前后保存快照。权限矩阵用于验证实际边界，不能用前端菜单显示结果替代后端授权测试。

## 系统设置

进入“系统 → 系统设置”，需要 `system:read`。设置页统一管理系统信息、登录支持、档案浏览、访问安全、开发者模式、菜单显示、科室配色和界面外观。

### 系统信息

可配置：

- 系统名称、简称和英文名称；
- 所属机构；
- 系统简介；
- 登录页环境标签和说明；
- 支持团队、电话、邮箱、服务时间和补充说明。

管理员联系信息默认不公开。只有同时启用联系信息并允许登录页公开显示，匿名配置接口才会返回相应内容。

### 图片来源与档案浏览

| 选项 | 行为 |
| --- | --- |
| 本地图片 `local` | 使用 Nginx/NAS/HTTP/本地目录读取 |
| OSS 图片 `oss` | 优先读取已迁移 OSS 图片，失败时降级到非 OSS 来源 |

单份病案可以混合 OSS 与非 OSS 图片。后端逐张解析，不要求整份病案一次性迁移完成。

档案浏览还可以配置：

- 默认缩略图或列表；
- 单页或连续滚动；
- 缩略图目标宽度；
- 首批渲染数量；
- 自动适应预览区域；
- 是否记住当前病案的选中图片；
- 水印和身份证完整显示/复制策略。

### 目录路由规则

入口为“系统设置 → 档案浏览 → 目录路由规则”，读取需要 `system:read`，保存或恢复需要 `system:manage`。规则单独保存，不随页面其他设置提交。

1. 选择“精确目录”或“年月”，输入原目录形式的日期，例如 `2026.06.05` 或 `24.04`。
2. 选择已配置的默认、BA01、BA02、BA03 或通用节点。重复条件、非法日期和未配置目标会被拒绝。
3. 在“目录匹配预览”输入完整目录，确认命中规则和目标节点，再保存。

优先级固定为精确目录 → 年月 → 通用节点，与列表顺序无关。`24.04` 与 `2024.04` 分别匹配，不转换文件路径；无目录记录仍使用默认节点。

未设置时沿用内置日期分流；保存空规则列表表示所有有目录记录使用通用节点。“恢复内置目录规则”清除服务器覆盖，恢复原规则。配置损坏时可明确恢复内置规则；保存结果未知时先重新加载核对，不直接重复保存。

此处维护目录到节点的映射；Nginx 地址、账号和密码仍在后端部署配置维护。规则不会移动图片、重命名目录或重置迁移记录。长任务不冻结全任务的路由配置，修改前应先暂停相关导出或迁移。

### 运行参数

“系统设置 → 运行参数”用于调整现有登录限流、会话与日志留存等参数；后端仍校验值域和管理权限。

- 敏感配置在确认前固定本次提交内容，确认、保存和恢复期间不能重复提交。
- “运行参数待重新核对”不代表保存失败：请求结果可能未知，也可能已保存但读取最新配置失败。保留当前编辑，点击重新加载核对后再决定操作。
- 单项“恢复配置默认”会清除服务器覆盖并回读整组参数；确认框会提示其他未保存编辑将被丢弃。
- 切换页面后无法撤回已发送写入，返回时如提示待核对，应先读取服务器状态。

### 组件与界面验收

登录后可访问 `/ui-components`，搜索基础控件、共享组件和反馈示例，切换示例状态、明暗主题及动效。示例使用内存合成数据，不发起病案写入；展示效果不能替代业务权限、真实浏览器或辅助技术验收。

“运维 → 认证接口测试 → OSS 检查”需要 `user:manage` 进入测试台，并按每个后端接口的实际权限运行固定只读检查。结果只保留白名单摘要，不能用检查通过推断上传、迁移或真实 OSS 故障恢复已验收。

### 菜单显示

管理员可以控制部分菜单是否显示。菜单隐藏仅影响界面，不撤销用户已有权限，也不替代后端校验。需要真正禁止访问时，应修改角色权限。

### 访问安全

可配置：

- 水印显示和透明度；
- 身份证完整显示和复制；
- 每日 IP 切换限制；
- 是否关闭 IP 访问限制（仅限明确的受控环境）。

涉及真实患者数据时，不建议关闭访问限制。

### 开发者模式

开发者功能默认关闭，并区分两个独立选项：

- **旧档案袋只读兼容**：仅在启动配置允许、请求经过可信本机 Nginx 且客户端命中管理员配置的 IP/CIDR 白名单时，允许指定旧档案袋只读接口访问。无效或过期 Token 不获得兼容回退，也不开放任意跨域来源。
- **登录后 API 业务权限旁路**：独立的 `developerModeApiAccessEnabled` 默认关闭。只有同时满足开发者模式、可信来源和有效账号/Token 时才放宽业务权限，包括写接口；审计仍使用真实登录身份。未启用此旁路时，有效 JWT 继续遵守账号原权限。

生产环境与真实患者数据环境应保持两个选项关闭，不能将只读兼容的范围误认为 API 权限旁路也只读。

开发者模式不会取消外部影像 Ticket 的 HMAC、时间戳、nonce 和来源 IP 校验，也不能绕过自动只读降级或主动维护模式，不应成为凭据管理和维护保护的后门。

生产环境、真实患者数据环境和可被非开发网络访问的环境必须关闭开发者模式。

### 页面外观

可配置：

- 页面标题容器；
- 全局圆角；
- 主题和导航外观；
- 管理概览卡片的显示、大小、顺序、置顶和颜色。

## 维护模式

进入“运维 → 运维诊断中心 → 维护模式”，需要 `system:read`。

- **主动维护只读**：管理员在升级、数据库维护或批量修复前手工开启，并填写原因；
- **自动只读降级**：数据库、迁移、临时目录或首选图片来源等关键检查失败时自动触发；
- 退出主动维护不会清除仍存在的自动降级；
- 系统处于只读时，查询和诊断尽量保持可用，业务写入、导入、迁移和新任务创建会被拒绝。

完整操作见 [运维诊断中心](./operations-center.md)。

## 登录与会话安全

- 用户名或密码错误返回统一提示；
- 登录失败过多会触发限流；
- 用户退出时后端撤销当前 Token，前端再清理会话；
- 密码修改、重置和首次改密会增加密码版本，使旧 Token 失效；
- 服务端异常不把内部堆栈返回浏览器；
- Token 撤销事实持久化在数据库，服务重启后撤销依然有效；撤销写入失败时登出会明确报错，不会返回伪成功。

## 设置保存规则

1. 优先读取服务端 `mr_system_settings`；
2. 服务端不可用时，部分界面设置可回退浏览器本地配置；
3. 服务端字符串会恢复为 boolean、number 或枚举；
4. 数值越界时限制到允许范围；
5. 保存后通知已打开页面刷新；
6. 开发者模式只有服务端保存成功才会改变；目录路由和运行参数使用服务器核对状态，不从浏览器缓存推断已生效。

排查设置异常时检查配置来源、最近同步时间、未保存状态和浏览器 `localStorage`。

## 管理注意事项

- 不要在页面设置中保存数据库密码、JWT、AES、HMAC 或 OSS 密钥；
- 正式环境必须修改初始管理员密码；
- 修改角色后验证菜单、路由、接口和权限矩阵结果；
- 下载和 PDF 权限应按岗位最小化授权；
- 开发者模式只能用于受控联调；
- 切换图片来源前抽样检查已迁移、未迁移和混合来源病案；
- 批量导入、迁移和装箱更新应先备份并在副本验证；
- 进入或退出维护模式后应重新执行全面体检并保留审计记录。
