## 生成方式

在 `vitepress-doc` 目录执行：

```bash
npm run docs:changelog
```

`docs:dev:user`、`docs:dev:internal`、`docs:build:user` 和 `docs:build:internal` 也会在启动或构建前自动刷新本页。

可通过环境变量 `MRR_CHANGELOG_LIMIT` 调整记录数量，允许范围为 1～1000。
