# 数据交换操作检查表

在数据交换中心执行正式导入前，按以下顺序确认：

1. 已选择正确的数据集并使用该数据集的最新模板。
2. 病案号、上架号、身份证号等编号字段没有被表格软件转换为科学计数法。
3. 已完成预校验，错误行为零，并核对预计新增、更新和重复数量。
4. 大批量导入前已备份数据库，并先用少量数据验证关联结果。
5. 正式导入后以接口返回的实际统计为准，再回到业务页面抽样核对。
6. 导出文件已保存在受控目录，没有上传到公开 Issue、代码仓库或普通聊天工具。
7. 使用 Excel 或 WPS 抽查导出文件时，公式样式文本不会被执行，前导零和长编号保持完整；重新导入后保护前缀会自动还原。
8. 首次部署扫描记录交换功能后，确认 Flyway 已完成 `20260723011000`，并存在 `(folder, filename)` 复合索引。

扫描路径索引由核心数据交换 PostgreSQL 16 集成测试在同一个数据库容器中验收，避免重复启动容器和重复执行完整 Flyway 迁移。

扫描记录超过 100,000 行时，不应拆成大量浏览器上传操作；应改用分卷 CSV、后端流式 COPY 和异步迁移任务。
