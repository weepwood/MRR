# 数据交换中心

进入“数据治理 → 数据交换中心”，或从患者管理等业务页面点击“数据导入导出”。

数据交换中心是核心业务数据搬运的统一入口。业务页面负责查询、编辑和分析；模板下载、文件预校验、确认导入和条件导出集中在本页面完成。

## 支持的数据集

| 数据集 | 导入 | 导出 | 说明 |
| --- | --- | --- | --- |
| 患者信息 `mr_patient` | 支持 | 支持 | 复用患者管理的校验、去重和脱敏规则 |
| 统计数据 `mr_statistics` | 支持 | 支持 | 非空上架号更新，无上架号按完整业务字段去重 |
| 病案主档 `mr_archive` | 不支持 | 支持 | 由统计数据和关联触发器维护，禁止绕过主数据规则直接写入 |
| 档案装箱 `mr_archive_box_record` | 支持 | 支持 | 导入前必须解析稳定 `archive_id` |
| 扫描记录 `mr_scan` | 小批量支持 | 支持 | 浏览器单次最多 100,000 行；三千万级迁移继续使用分卷任务 |

用户、角色、系统设置、访问日志和审计日志不属于核心业务数据交换范围，不在这里提供批量导入，避免覆盖账号权限和审计证据。

## 统一导入流程

1. 选择目标数据集并下载模板。
2. 按英文表头整理 CSV、XLSX 或 XLS 文件。
3. 上传后先执行“校验文件”。
4. 核对总行数、有效唯一行、预计新增、预计更新、重复行和错误行。
5. 只有错误行为零且校验通过，才能执行“确认导入”。
6. 导入完成后回到业务页面核对数量、关联关系和抽样数据。

CSV 支持 UTF-8、UTF-8 BOM、UTF-16LE、UTF-16BE 和 GB18030。错误明细最多展示 200 条，但系统仍会统计全部错误行；身份证等敏感值会脱敏。

预校验结果只代表当前文件和当前数据库状态；正式导入前若数据库发生变化，系统会在事务内重新执行去重与关联判断，以正式导入结果为准。

## 患者信息

模板字段：

```text
bah,name,idcard,ruyuan,admissiontime,department,bingqu,chuangwei
```

规则：

- `bah` 必填。
- `ruyuan` 使用 `YYYY-MM-DD`。
- `admissiontime` 使用 `YYYY-MM-DD HH:MM` 或 `YYYY-MM-DD HH:MM:SS`。
- 病案号和身份证号疑似被 Excel 转为科学计数法时拒绝导入。
- 文件内完全重复和数据库内完全重复的记录会跳过。
- 患者管理页面不再维护单独的导入、导出流程，统一跳转到数据交换中心。

## 统计数据

模板字段：

```text
bah,cid,openerno,date,type,pages,sjh,patientname,inpatientdepartment,patientid,dischargedate
```

规则：

- `bah` 与 `sjh` 不能同时为空。
- 数字病案号达到 `10000000` 时必须提供上架号。
- 非空 `sjh` 命中现有记录时更新。
- 无上架号记录按完整业务字段精确去重。
- 正式写入继续由数据库触发器同步 `mr_archive`。
- 病案号和上架号只去除首尾空格，不补零、不改变原始长度。

## 病案主档

`mr_archive` 只提供条件导出，不提供直接导入。

这是因为病案主档承担稳定 `archive_id`、唯一上架号和多表关联。直接导入会绕过统计触发器和关联解析规则，可能导致：

- 同一上架号对应多个病案。
- `mr_statistics`、`mr_scan`、装箱记录指向错误主档。
- 无上架号病案被错误合并。
- 来源统计记录不可追踪。

需要补充主档时，应先导入统计数据；扫描或装箱导入也会在有可靠上架号时创建最小主档。

## 档案装箱

模板字段：

```text
bah,sjh,box_no,expected_box_no,status,remark
```

支持状态：

```text
NORMAL,MISSING,MISPLACED,CONFLICT,OTHER
```

规则：

- 除 `MISSING` 外必须填写实际箱号。
- 优先按上架号关联病案主档。
- 缺少上架号时，只允许能够唯一解析的低位病案号。
- 无法获得稳定 `archive_id` 或同一病案在文件中存在冲突时整批拒绝。
- 重复导入会更新同一病案的装箱记录，不新增重复记录。

## 扫描记录

小批量模板字段：

```text
sjh,bah,brxh,folder,filename,btype,filesize
```

规则：

- `folder` 和 `filename` 必填，并作为受控定位条件。
- `bah` 与 `sjh` 不能同时为空。
- `btype` 允许 `0`～`15`，空值按 `0` 处理。
- `filesize` 是纯数字字节数，不能写 `KB`、`MB`。
- 同一文件中相同 `folder + filename` 对应不同数据时拒绝。
- 数据库存在相同路径多条历史记录时拒绝，必须先清理冲突。
- 完全相同记录跳过；相同路径的模板字段变化时更新；新路径新增记录并关联病案主档。
- 导出按 `id` 升序，`afterId` 可用于手工分卷。

三千万级全量扫描数据不能通过浏览器上传。应使用每卷 50 万～100 万行的 CSV、后端流式 `COPY`、任务记录、SHA-256 校验、失败重试、暂停恢复和主键游标导出。

## 导出限制与安全

- 单次条件导出最多 100,000 行。
- 导出 CSV 使用英文模板字段，除病案主档外均可重新导入。
- 为防止 Excel/WPS 公式注入并保留前导零和长编号，系统会增加可逆文本保护；重新导入时自动还原。
- 导出文件可能包含身份证号、患者姓名和目录信息，只能保存在受控目录。
- 不要把真实导出文件上传到公开 Issue、聊天工具或代码仓库。
- 大批量导入前先备份数据库，并用少量数据验证字段、编码、去重和关联结果。
