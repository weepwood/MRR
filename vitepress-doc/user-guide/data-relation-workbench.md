# 数据关系工作台

数据关系工作台用于从“单张表”视角切换到“单份病案”视角，查看 `mr_archive` 与统计、患者、扫描、装箱和迁移数据之间的关系。

入口：**数据治理 → 数据关系工作台**。

## 关系模型

```text
mr_statistics ───────► mr_archive ◄────── mr_archive_box_record
                           │
                           ├──────────────► mr_scan
                           │                    │
                           │                    └──► image_migration_log
                           │
                           └── mr_patient（当前仅按 BAH 遗留匹配）
```

`mr_archive` 是病案主实体；`mr_statistics`、`mr_scan` 和 `mr_archive_box_record` 应通过 `archive_id` 关联。`mr_patient` 当前没有 `archive_id`，工作台只按 BAH 兼容匹配，不会把 `patient_id` 猜测为身份证号进行关联。

## 关系总览

总览显示：

- 病案主档数量；
- 各核心表的已关联数、缺失数和覆盖率；
- 最近一次数据质量检查的严重异常和警告数量；
- 与 `archive_id`、孤立记录、编号冲突相关的检查结果。

`mr_scan` 约有数千万行。页面打开时不会执行全表 `COUNT(archive_id)`，而是使用 PostgreSQL 的表统计信息估算覆盖率。精确结果以定时数据质量检查和外键验收为准。

## 病案关系查询

支持按以下字段搜索：

- `archive_id`；
- 病案号 BAH；
- 上架号 SJH。

纯数字编号在比较时允许前导零差异，例如 `123` 与 `00000123` 会标记为“仅格式差异”，数据库仍保留原始编号。

选择病案后可查看：

- 病案主档；
- 统计记录；
- 患者记录；
- 装箱记录；
- 扫描汇总和前 50 条扫描样本；
- OSS 迁移汇总；
- 跨表字段对比和风险提示。

## 比较状态

| 状态 | 含义 |
| --- | --- |
| `EXACT` | 两个值完全一致 |
| `FORMAT_ONLY` | 仅前导零、空格等格式不同 |
| `CONFLICT` | 实际值不同，需要人工核对 |
| `MISSING` | 来源表缺少该字段 |
| `NO_CANONICAL` | `mr_archive` 主档缺少该字段 |

## 数据质量检查

标准检查默认每天凌晨执行，也可以在工作台手动执行。

扫描表相关的日常规则只检查最近 50 万条记录；`archive_id` 缺失总量通过 PostgreSQL 统计信息估算。这样可以避免每日任务对三千万级 `mr_scan` 进行无界分组和全表扫描。

主要规则包括：

- 最近扫描记录编号、页码和文件元数据缺失；
- `mr_scan.archive_id` 缺失估算；
- 最近扫描记录与主档编号不一致；
- 统计记录和装箱记录缺失或错连主档；
- 高位 BAH 缺少唯一 SJH；
- 忽略前导零后 SJH 重复；
- 患者 BAH 可以匹配多个主档；
- 迁移状态和 OSS 地址不一致；
- 最近扫描页疑似重复。

## 修复预览

第一阶段只提供修复预览，不写入数据库。

预览会显示：

- 当前异常记录；
- 候选 `mr_archive`；
- 建议动作；
- 候选关系是否唯一；
- 为什么当前不能自动执行。

即使候选主档唯一，第一阶段也不会自动修改 `archive_id`。后续开放确定性修复时，仍需经过“预览 → 确认 → 事务执行 → 重新检查 → 审计记录”。

## 编号比较函数

数据库函数：

```sql
app.numeric_code_key(text)
```

规则：

- 空白转换为 `NULL`；
- 纯数字编号忽略前导零；
- 非纯数字编号只去除首尾空格；
- 不修改原始业务编号。

可控规模的主档、统计、患者和装箱表已经建立比较键表达式索引。`mr_scan` 没有在 Flyway 中同步创建该表达式索引，以避免生产环境对数千万行大表执行阻塞式索引构建。

## 权限与安全

- 页面需要 `system:read` 权限；
- 不提供任意 SQL；
- 不提供全表 CRUD；
- 扫描样本有数量上限；
- 修复预览为只读；
- 患者遗留匹配结果不能视为外键关系。
