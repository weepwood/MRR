# 快速上手

## 进入系统

开发环境默认地址为 `http://localhost:9000`。实际部署地址由运维人员提供。

### 登录模式

生产或完整联调环境需要输入账号和密码。开发配置 `VITE_APP_DEMO_MODE=true` 时，前端会跳过认证接口以便单独浏览界面，但需要后端数据的业务页面仍可能无法正常加载。

仓库当前常用的本地管理员账号为：

```text
br_admin / br_password
```

::: warning
该账号只适合本地初始化和联调。正式环境必须修改默认密码，并通过角色权限限制菜单与接口访问。
:::

## 界面结构

MRR 使用现代 SaaS 管理端布局：

- **主导航轨道**：切换系统、业务、运维和帮助分组。
- **二级菜单**：进入当前分组下的功能页面。
- **顶部工具区**：显示标签页、主题、全屏、用户菜单等工具。
- **工作区**：展示当前业务页面。
- **标签页**：保留最近访问页面，支持快速切换和关闭。

影像档案袋属于沉浸式页面，不进入长期页面缓存。离开后再次进入时会重新恢复查询条件和数据。

## 页面标题和外观

系统设置支持两种页面标题容器：

- **页面同级**：标题直接位于工作区内容层级。
- **卡片**：标题显示在 Hero 卡片中。

两种模式均保持三行信息：英文标题、中文标题和页面说明。系统还支持调整全局圆角，业务卡片和 Element Plus 常用控件会同步变化。

## 常用列表操作

不同页面提供的筛选项不同，但通常包括：

1. 输入病案号、上架号、患者信息或关键字。
2. 选择日期、类型、科室或状态等条件。
3. 点击查询或重置。
4. 在表格或卡片列表中查看详情、编辑或执行批量操作。

不要假设所有列表都支持 Excel、CSV 或任意列导出；以当前页面实际显示的按钮为准。

## 打开影像档案袋

可以从记录、统计明细等页面进入，也可以直接使用 URL：

```text
/archive?bah=00001234
/archive?sjh=00789123
/archive?bah=10000000&sjh=00789123
/archive?id=123456789123456789
```

查询规则和输出操作见 [影像档案袋](./images.md)。

## 打开文档

进入“帮助 → 帮助与文档”，选择：

- 用户手册
- 内部文档
- 实时 API 文档

内部文档和实时 API 文档需要管理员或 `system:read` 权限。系统会在打开前申请短期文档访问会话。

## 退出登录

从右上角用户菜单退出。退出后，登录会话和文档访问 Cookie 会被清除。
