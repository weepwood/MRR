# 快速上手

## 登录系统

1. 打开浏览器访问系统地址
2. 输入用户名和密码
3. 点击"登录"按钮

**默认账号**:
- 管理员: `br_admin` / `br_password`
- 操作员: `br_operator` / `br_password`
- 查看者: `br_viewer` / `br_password`

> ⚠️ 生产环境首次登录后请立即修改密码。

## 界面导航

```
┌────────────────────────────────────────────┐
│  Logo     导航菜单             用户信息    │  ← 顶部导航栏
├──────────┬─────────────────────────────────┤
│          │                                 │
│  功能    │      主内容区域                  │
│  菜单    │                                 │
│          │                                 │
│          │                                 │
├──────────┴─────────────────────────────────┤
│                底部状态栏                    │  ← 页脚
└────────────────────────────────────────────┘
```

### 主要区域说明

- **左侧菜单**: 功能模块导航
- **顶部栏**: 系统标题、用户信息、通知、设置
- **主内容区**: 当前功能模块的操作界面
- **标签页**: 支持多标签页操作，类似浏览器

## 基本操作

### 搜索与筛选

大多数列表页面支持：
- 关键字搜索
- 日期范围筛选
- 状态筛选
- 高级搜索（多条件组合）

### 数据导出

列表页面支持导出功能：
- 导出为 Excel
- 导出为 CSV
- 自定义导出列

### 分页操作

- 支持每页显示 10/20/50/100 条
- 快速跳转到指定页
- 显示总记录数

## 个人设置

点击右上角用户头像：

- **修改密码**: 更改登录密码
- **个人信息**: 查看和编辑个人资料
- **主题设置**: 切换亮色/暗色模式
- **退出登录**: 安全退出系统
