# 快速上手

## 1. 登录到医院提供的入口

打开医院运维人员提供的 MRR 地址，使用本人账号登录。没有账号时，先按[账号申请与登录](./accounts.md)提交申请，或联系管理员。首次登录提示修改密码时，请按页面要求完成改密，再重新登录。

::: tip 第一次使用
建议先使用获准的测试病案完成一次“查询 → 浏览 → 核对”的只读练习。文档中的示意编号均为合成示例，实际访问地址、可用操作及菜单取决于部署环境和账号权限。
:::

## 2. 认识工作区

进入系统后，先认识三个主要区域：导航用于选择功能，顶部工具区用于切换页面与个人设置，工作区用于完成当前任务。

- **主导航轨道**：切换系统、业务、运维和帮助分组。
- **二级菜单**：进入当前分组下的功能页面。
- **顶部工具区**：显示标签页、主题、全屏、用户菜单等工具。
- **工作区**：展示当前业务页面。
- **标签页**：保留最近访问页面，支持快速切换和关闭。

影像档案袋属于沉浸式页面，不进入长期页面缓存。离开后再次进入时会重新恢复查询条件和数据。

## 3. 按任务选择菜单

| 你要完成的任务 | 对应入口 |
| --- | --- |
| 找到病案或患者 | 业务 → 记录管理 / 患者管理 |
| 浏览、打印或输出病案图片 | 业务 → 影像档案袋 |
| 查看数量与趋势 | 业务 → 病案扫描统计 / 统计明细 |
| 查看实体档案位置 | 业务 → 档案装箱 |
| 检查多表关联、批量导入导出 | 数据治理 → 数据关系工作台 / 数据导入导出 |
| 管理用户、角色和配置 | 系统 → 用户管理 / 权限管理 / 系统设置 |
| 排查故障 | 运维 → 运维诊断中心 |

账号没有对应权限时，菜单可能不会显示，直接访问路由也会被权限校验拦截。

## 页面标题和外观

系统设置支持两种页面标题容器：

- **页面同级**：标题直接位于工作区内容层级。
- **卡片**：标题显示在 Hero 卡片中。

两种模式均保持三行信息：英文标题、中文标题和页面说明。系统还支持调整全局圆角，业务卡片和 Element Plus 常用控件会同步变化。

## 4. 查询列表与翻页

不同页面提供的筛选项不同，但通常包括：

1. 输入病案号、上架号、患者信息或关键字。
2. 选择日期、类型、科室或状态等条件。
3. 点击查询或重置。
4. 在表格或卡片列表中查看详情、编辑或执行批量操作。

不要假设所有列表都支持 Excel、CSV 或任意列导出；以当前页面实际显示的按钮为准。

## 5. 打开影像档案袋

可以从记录、统计明细等页面进入，或打开影像档案袋后直接填写查询表单。先选择查询方式，再输入病案号、上架号或身份证号。不要自行拼接含真实身份证号的 URL，也不要把明文号码分享给其他人。

查询规则和输出操作见 [影像档案袋](./images.md)。

## 打开文档

进入“帮助 → 帮助与文档”，选择：

- 用户手册
- 内部文档
- 实时 API 文档

内部文档和实时 API 文档需要管理员或 `system:read` 权限。系统会在打开前申请短期文档访问会话。

## 退出登录

从右上角用户菜单退出。系统会请求撤销当前会话并清理本机登录状态；网络故障时本地退出不一定代表服务端已经撤销成功。如收到撤销失败提示，请联系管理员核对会话状态。

## 第一次使用的业务检查清单

建议先使用管理员批准的测试病案熟悉工作台，再开始处理正式病案。登录后核对本人账号与权限，确认查询入口、原始编号及当前病案，尝试只读浏览；需要编辑或输出时再确认相应授权。浏览器显示宽窄屏差异时，可使用页面自己的筛选、折叠与分页，不通过浏览器缩放掩盖操作区遮挡问题。

| 页面状态 | 操作建议 |
| --- | --- |
| 首次加载 | 等待请求完成，不将骨架屏或空白当作无记录 |
| 无结果 | 核对编号、筛选条件与查询范围，再重新查询 |
| 读取失败 | 记录提示并刷新；旧数据可能仅代表上次成功结果 |
| 写入结果未知 | 先核对服务端记录，不连续点击提交 |
| 权限不足 | 联系管理员核对角色与资源范围，不更换他人账号 |

建议按 [病案与记录](./patients.md)、[影像档案袋](./images.md)、[常见问题](./faq.md) 的顺序阅读。
