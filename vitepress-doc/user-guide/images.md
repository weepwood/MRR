# 影像档案袋

影像档案袋用于查询和浏览病案扫描图片。它不是 DICOM 诊断工作站，不提供窗宽窗位、医学测量或诊断标注。

## 打开方式

### 病案号查询

```text
/archive?bah=123
```

病案号小于 `10000000` 时可以单独查询。编号保留数据库原始格式，不自动补零。

### 上架号查询

```text
/archive?sjh=456
```

上架号非空且唯一时可以单独查询。

### 高位病案号查询

```text
/archive?bah=10000000&sjh=456
```

病案号大于或等于 `10000000` 时可能重复，必须同时提供上架号，并按两者组合定位档案。

### 身份证查询

```text
/archive?id=123456789123456789
```

处理流程：

1. 系统校验身份证格式。
2. 后端查询该患者关联的全部病案，并返回脱敏信息。
3. 页面展示病案列表，可切换查看不同病案。
4. 前端使用 `router.replace` 将地址栏中的身份证明文替换为服务端不透明令牌。
5. 刷新、前进和后退时通过令牌恢复查询。

不要在截图、日志或工单中复制完整身份证号。

## 编号与图片目录

病案号 `bah`、上架号 `sjh` 会参与本地图片目录定位：

- 只去除首尾空格。
- `123` 保持为 `123`。
- `00000123` 保持为 `00000123`。
- 不得为了显示整齐自动补齐为 8 位。

数据库编号与图片文件夹名称不一致时，即使记录存在也可能无法访问图片。

## 最近查询

查询卡片提供“最近查询”：

- 仅在成功加载到图片后写入。
- 最多保留 20 条。
- 同一病案再次查询时移动到最前并更新时间和图片数量。
- 支持点击重新查询、删除单条和清空全部。
- 同一浏览器多标签页之间同步。
- 数据只保存在当前浏览器 `localStorage`。
- 不保存身份证号、患者姓名、科室或后端访问令牌。

## 页面区域

查询成功后通常包含：

- 患者和病案摘要。
- 身份证查询场景下的关联病案列表。
- 图片类型筛选。
- 缩略图或列表导航。
- 单页或连续滚动预览。
- 当前图片序号和选择状态。
- 下载、打印和 PDF 导出操作。

未查询到图片时，不显示下载、打印和 PDF 操作。

## 图片类型

类型 `0` 表示“暂未分类”，正式类型为 `1`～`15`。完整类型名称见 [病案类型](./medical-record-types.md)。

“暂未分类”与“14-其它”不同：前者尚未确认，后者已经确认属于其它资料。

## 图片来源

管理员可以在系统设置中选择：

| 来源 | 行为 |
| --- | --- |
| 本地图片 `local` | 默认值，使用本地或 NAS 图片服务 |
| OSS 图片 `oss` | 对存在 `oss_url` 的记录生成签名地址 |

OSS 模式下，未迁移、签名为空或签名失败的图片会回退本地地址。服务端 ZIP 下载当前仍从本地存储读取。

## 浏览模式

系统设置可以控制：

| 设置 | 说明 |
| --- | --- |
| 影像栏模式 | 缩略图或列表 |
| 预览模式 | 单页或连续滚动 |
| 缩略图目标宽度 | 同步影响导航区域宽度 |
| 首批渲染数量 | 控制首次挂载的图片数量 |
| 自动适应预览区域 | 开启时按容器缩放，关闭时允许按原始尺寸滚动 |
| 记住选中图片 | 按病案号和上架号恢复选中项 |

## 全屏预览

单页模式下点击图片可进入全屏预览：

- 从当前图片打开。
- 使用上一张、下一张按钮切换。
- 第一张和最后一张禁止越界，不循环跳转。
- 全屏切换后，档案袋中的当前图片同步更新。
- 关闭全屏后保留最后查看位置。

## 下载、打印与 PDF

### 下载档案袋

整袋下载会同时携带病案号和上架号。高位病案号缺少上架号时后端会拒绝请求，避免下载到错误目录。

### 打印选中

只处理当前勾选图片。打印前检查页序、纸张方向、缩放比例和选中数量。

### 导出 PDF

PDF 在浏览器中生成：

1. 按选择顺序读取图片 URL。
2. 使用 `fetch` 获取 Blob。
3. 通过 Canvas 转换为 JPEG，透明背景填充为白色。
4. 超大图片按浏览器安全尺寸等比缩放。
5. 根据图片方向创建 A4 横向或纵向页面。
6. 保持比例居中写入 PDF。
7. 生成 Blob 并下载。

图片服务必须允许管理端来源通过 CORS 读取图片。前端使用 `credentials: omit`，通常不需要 `Access-Control-Allow-Credentials`。

## 访问水印

档案袋可显示包含当前用户标识和时间的重复斜向水印：

- 时间按分钟刷新。
- 普通预览、连续滚动和全屏预览均可显示。
- 水印不拦截鼠标、触摸或键盘操作。
- 管理员可在系统设置中关闭或调整透明度。

## 常见问题

### 查询提示上架号必填

当前病案号大于或等于 `10000000`，请同时输入对应上架号。

### PDF 导出失败

检查图片 HTTP 状态、空文件、图片解码和 CORS。任意一张图片读取失败都会中止本次导出。

### 图片为空或无法打开

检查编号原始格式、病案号与上架号组合、图片来源设置、本地目录或 OSS 状态，并结合浏览器网络面板和后端日志定位。

更多问题见 [常见问题](./faq.md)。
