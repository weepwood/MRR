# 影像档案袋

影像档案袋用于浏览病案扫描图片文件。它不是 DICOM 诊断工作站，不提供窗宽窗位、医学测量或诊断标注。

## 打开方式

### 病案号查询

```text
/archive?bah=00001234
```

病案号小于 `10000000` 时可单独查询。

### 上架号查询

```text
/archive?sjh=00789123
```

上架号唯一时可单独查询。

### 高位病案号查询

```text
/archive?bah=10000000&sjh=00789123
```

病案号大于或等于 `10000000` 时可能重复，必须同时提供上架号。

### 身份证查询

```text
/archive?id=123456789123456789
```

处理流程：

1. 系统校验 15 位或 18 位身份证格式。
2. 后端查询该患者全部病案，并返回脱敏身份证信息。
3. 页面展示病案列表，可点击不同病案切换图片。
4. 前端使用 `router.replace` 将地址栏中的身份证明文替换为服务端生成的不透明令牌。
5. 刷新、前进和后退时可通过令牌恢复查询。

身份证令牌使用随机 IV 的 AES-GCM 加密，并校验篡改。不要在截图、日志或工单中再次复制明文身份证号。

## 页面区域

查询成功后，页面通常包含：

- 患者和病案摘要
- 患者全部病案切换列表（身份证查询场景）
- 图片类型筛选
- 缩略图或列表导航
- 单页或连续滚动预览
- 当前图片序号和选择状态
- 下载、打印和 PDF 导出操作

未查询到档案或图片为空时，不显示“下载档案袋”“打印选中”和“导出 PDF”等档案操作。

## 浏览模式

系统设置可以控制档案袋的默认行为：

| 设置 | 说明 |
| --- | --- |
| 影像栏模式 | 缩略图或列表 |
| 预览模式 | 单页或连续滚动 |
| 缩略图目标宽度 | 同步影响中间导航栏宽度 |
| 首批渲染数量 | 控制首次加载的图片数量 |
| 自动适应预览区域 | 开启时按容器缩放；关闭时按原始尺寸并允许滚动 |
| 记住选中图片 | 按病案号和上架号恢复上次选中项 |

设置保存后，已打开的档案袋页面会接收配置变更并刷新相关行为。

## 单页与全屏预览

单页模式下点击图片可进入全屏预览：

- 从当前图片索引打开，而不是固定从第一张开始。
- 使用上一张、下一张按钮切换。
- 第一张和最后一张禁止越界，不循环跳转。
- 全屏切换后，档案袋中的当前选中图片同步更新。
- 关闭全屏后保留最后查看位置。

## 选择图片

勾选图片后可以执行打印或 PDF 导出。选择前应确认：

- 图片属于当前同一个病案和上架号。
- 图片顺序符合输出顺序。
- 图片地址可访问。
- 需要输出的页面没有遗漏。

没有选中图片时，“打印选中”和“导出 PDF”保持禁用。

## 下载档案袋

下载整袋时，前端会同时携带病案号和上架号。高位重复病案号缺少上架号时，后端会拒绝请求，避免下载到同病案号下的错误目录。

## 打印选中

“打印选中”只处理当前勾选图片。打印结果受浏览器打印设置影响，正式输出前应检查页序、纸张方向和缩放比例。

## 导出 PDF

PDF 完全由浏览器生成：

1. 按当前选择顺序请求图片 URL。
2. 使用 `fetch` 获取图片 Blob。
3. 通过 Canvas 转换为 JPEG，透明背景填充为白色。
4. 超大图片按浏览器安全尺寸等比缩放。
5. 根据图片方向选择 A4 横向或纵向页面。
6. 保持原图比例居中写入 PDF。
7. 生成 Blob 并下载。

文件名格式：

```text
{病案号}-selected.pdf
{病案号}-{上架号}-selected.pdf
```

### CORS 要求

图片服务必须允许管理端来源读取图片，例如：

```nginx
add_header Access-Control-Allow-Origin "http://localhost:9000" always;
add_header Access-Control-Allow-Methods "GET, HEAD, OPTIONS" always;
add_header Access-Control-Allow-Headers "Content-Type, Range" always;
```

前端使用 `mode: cors` 和 `credentials: omit`。不需要 `Access-Control-Allow-Credentials`，也不会调用 Spring Boot 图片代理。浏览器提示跨域错误时，应修复图片服务配置，而不是关闭浏览器安全策略。

## 访问水印

档案袋可显示重复斜向水印，内容包含当前用户标识和当前时间：

- 时间按分钟刷新。
- 普通预览、连续滚动和全屏预览均可显示。
- 水印不拦截鼠标、触摸或键盘操作。
- 在系统设置中可以关闭或调整透明度。
- 离开档案袋后会移除水印和刷新定时器。

## 常见问题

### 查询提示上架号必填

当前病案号大于或等于 `10000000`。请同时输入对应上架号。

### PDF 导出失败

依次检查图片 HTTP 状态、空文件、图片解码和 CORS。只要其中一张图片读取失败，系统会停止本次导出。

### 刷新后查询条件丢失

确认地址栏包含 `bah`、`sjh` 或身份证令牌 `id` 参数。旧格式 `/archive/:bah` 会自动转换为具名查询参数。

### 图片为空或无法打开

检查病案号与上架号是否匹配、图片服务地址是否正确、文件是否存在，以及 OSS 迁移和数据质量检查是否报告异常。
