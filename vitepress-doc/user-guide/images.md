# 影像浏览

## 支持的格式

- DICOM（.dcm）
- JPEG / PNG / BMP
- 多帧 DICOM 影像

## 影像查看器

### 打开影像

1. 在扫描记录列表，点击"查看影像"
2. 影像查看器在新标签页打开

### 基本操作

| 操作 | 方式 | 说明 |
|------|------|------|
| 缩放 | 滚轮 / 双击 | 放大或缩小影像 |
| 平移 | 鼠标拖拽 | 移动影像位置 |
| 旋转 | 右键菜单 | 90° 旋转 |
| 复位 | 工具栏按钮 | 恢复原始视图 |
| 全屏 | 工具栏按钮 | 全屏显示影像 |

### 窗宽窗位

- **左键拖拽**: 调整窗宽/窗位
- **预设值**: 快速切换预设窗宽窗位（如肺窗、骨窗、软组织窗）
- **复位**: 恢复默认窗宽窗位

### 测量工具

- **距离测量**: 测量影像中两点距离
- **角度测量**: 测量角度
- **面积测量**: 测量区域面积

## 序列浏览

对于多帧影像（如 CT 序列）：

| 功能 | 说明 |
|------|------|
| 播放/暂停 | 自动逐帧播放 |
| 帧选择 | 拖动滑块或点击跳转到指定帧 |
| 播放速度 | 调整播放速度（1x、2x、4x） |

## 影像导出

- **截图**: 当前视图保存为 PNG
- **导出原始 DICOM**: 下载原始 DICOM 文件
- **批量导出**: 选择多个扫描记录批量导出

## 影像上传

### 上传方式

1. **单个上传**: 在新增扫描记录时选择文件
2. **批量上传**: 支持多文件同时上传
3. **拖拽上传**: 将文件拖拽到上传区域

### 文件要求

- 支持格式: DICOM、JPEG、PNG
- 单文件最大: 100MB（可配置）
- 单次上传最大: 500MB

### 上传进度

- 显示上传进度条
- 支持断点续传（大文件）
- 上传完成后自动刷新列表
