# MRR 用户指南

MRR 用于管理医疗机构的病案扫描记录和病案图片文件。当前系统围绕病案号、上架号、患者信息、扫描记录、档案装箱和访问审计组织功能，不是医学诊断阅片工作站。

> 本手册对应 `dev-no-login` 分支在 2026-07-15 的开发快照。不同账号能看到的菜单由角色权限决定。

## 推荐使用流程

1. 在“记录管理”或“统计明细”中找到目标病案。
2. 通过病案号、上架号或身份证进入“影像档案袋”。
3. 在档案袋中切换病案、筛选图片类型并选择需要输出的页面。
4. 根据需要下载整袋、打印选中图片或在浏览器中导出 PDF。
5. 在“统计分析”“病案统计”中核对数量与趋势。
6. 管理员通过“日志管理”“图片访问审计”“系统监控”和“服务状态”检查运行情况。

## 当前重要规则

### 病案号与上架号

- 病案号和上架号在 URL、界面与接口中统一显示为 8 位数字。
- 病案号 `< 10000000` 时可仅使用病案号查询。
- 病案号 `>= 10000000` 时必须同时提供上架号，避免高位重复病案号匹配错误。
- 上架号唯一时可单独查询。

### 身份证查询

可直接访问：

```text
/archive?id=123456789123456789
```

查询成功后，系统会用服务端生成的不透明令牌替换地址栏中的身份证明文，并保留当前选择的病案号和上架号。页面和接口返回只显示脱敏身份证信息。

### PDF 导出

“导出 PDF”由浏览器直接读取所选图片并生成文件。图片服务必须允许当前管理端来源通过 CORS 读取图片，否则导出会失败。系统不会通过后端代理图片来绕过跨域限制。

## 文档入口

从“帮助 → 帮助与文档”打开：

- **用户手册**：已登录账号可访问。
- **内部文档**：需要管理员或 `system:read` 权限。
- **实时 API 文档**：需要管理员或 `system:read` 权限。

系统会为文档签发短期 HttpOnly 访问 Cookie。退出登录后文档访问会话会被清除。

## 功能边界

当前代码没有提供以下通用诊断工作站能力：

- DICOM 窗宽窗位或医学测量工具
- 多帧 DICOM 播放和诊断标注
- 病案图片断点续传
- 邮件定时发送统计报表
- 在用户界面中配置数据库、SMTP 或备份策略

需要确认某项功能时，应以当前页面、权限和接口行为为准，不应仅依据历史截图或旧文档。
