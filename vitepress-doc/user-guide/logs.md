# 日志查看

## 操作日志

系统自动记录所有用户的关键操作，供审计追溯。

### 查看日志

1. 左侧菜单点击"系统管理 → 操作日志"
2. 日志列表显示以下信息：
   - 操作时间
   - 操作用户
   - 操作类型
   - 操作对象
   - IP 地址

### 筛选日志

支持以下筛选条件：
- **用户**: 按操作用户筛选
- **操作类型**: 新增 / 修改 / 删除 / 查看 / 导出
- **时间范围**: 自定义起止时间
- **关键字**: 按操作内容搜索

### 日志详情

点击某条日志可查看完整信息：
- 请求详情（URL、方法、参数）
- 操作前后数据变化
- 响应状态
- 执行时长

## 系统监控

### 实时监控

系统监控面板展示：

| 指标 | 说明 |
|------|------|
| 在线用户 | 当前登录用户数 |
| 请求量 | 每分钟 API 请求数 |
| 响应时间 | API 平均响应时间 |
| 错误率 | API 错误占比 |
| 系统资源 | CPU、内存使用率 |

### 告警信息

- 系统异常告警
- 性能阈值告警
- 磁盘空间告警

### 访问记录

查看系统的访问日志：
- 登录/登出记录
- 失败登录尝试
- 异常访问行为
