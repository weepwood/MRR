# 病案与记录

MRR 将患者、扫描记录、统计明细、档案图片和档案装箱分成不同页面。具体可见字段与可执行操作受账号权限和后端数据影响。

## 记录管理

进入“业务 → 记录管理”。该页面用于：

- 按页面提供的条件查询扫描记录。
- 查看单条记录详情。
- 对支持编辑的字段执行修改。
- 多选记录后批量打包下载。
- 从病案号或上架号进入对应影像档案袋。

批量下载前应先核对选中数量和筛选条件，避免将不属于同一业务范围的记录一起导出。

## 患者管理

进入“业务 → 患者管理”。该页面用于查询患者基础信息和关联病案，不应把患者列表等同于扫描记录列表。

常见使用方式：

1. 输入患者相关查询条件。
2. 查看患者基础信息。
3. 进入其关联病案或扫描记录。
4. 根据病案号、上架号继续打开影像档案袋。

身份证属于敏感字段。系统中的身份证查询结果应使用脱敏值展示，日志和文档中也不应记录完整号码。

## 统计明细

进入“业务 → 统计明细”。页面以病案卡片或列表方式展示统计结果对应的病案明细，常见信息包括：

- 患者姓名
- 住院科室
- 出院日期
- 病案号
- 上架号
- 扫描页数

页面会根据当前容器宽度调整卡片列数和分页请求量，使非末页尽量保持完整行。点击目标病案可进入影像档案袋。

## 病案号和上架号规则

系统对查询值执行数字规范化并统一显示为 8 位：

| 场景 | 是否允许 | 示例 |
| --- | --- | --- |
| 低位病案号单独查询 | 允许 | `09999999` |
| 高位病案号单独查询 | 不允许 | `10000000` |
| 高位病案号 + 上架号 | 允许 | `10000000` + `00000456` |
| 上架号单独查询 | 允许 | `00000456` |

高位病案号可能重复，仅凭病案号无法唯一定位患者和图片目录，因此必须同时提供上架号。

## 档案装箱

进入“业务 → 档案装箱”。该模块用于管理档案箱、查看装箱汇总和箱内病案。

操作前建议核对：

- 箱号或箱体标识
- 箱内病案数量
- 病案号与上架号
- 装箱状态
- 页面统计卡片与明细数量是否一致

档案装箱属于归档管理，不会自动替代病案图片的下载、打印或 PDF 导出。

## OSS 迁移管理

进入“业务 → OSS 迁移管理”。该页面用于查看和管理病案图片迁移任务，包括迁移状态、校验状态和异常信息。

迁移完成不等于业务数据已经完全一致。运维人员还应结合：

- 系统监控中的数据质量检查
- OSS 迁移校验结果
- 图片访问审计
- 实际图片 URL 可访问性

## 操作注意事项

- 删除、批量下载、装箱和迁移属于高影响操作，执行前应确认筛选范围。
- URL、截图、日志和导出文件中不要保留完整身份证号。
- 页面显示数量与数据库统计不一致时，先检查筛选条件、分页和数据质量结果，不要直接修改历史 Flyway 迁移。
