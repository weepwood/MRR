# 更新说明

> 适用快照：`dev-no-login`，更新至 2026-07-15。当前仓库尚未发布稳定版本标签，本页按用户可见变化整理，不等同于正式 Release。

## 本次重点

### 影像档案袋

- 支持按病案号、上架号和身份证查询。
- 身份证查询完成后，地址栏中的身份证明文会替换为不透明令牌。
- 高位重复病案号必须同时提供上架号。
- 全屏预览增加上一张、下一张切换。
- 未查询到图片时隐藏下载、打印和 PDF 操作。
- 支持选择图片后由浏览器直接导出 PDF。
- 增加用户标识与当前时间水印，可在系统设置中关闭。
- 可设置默认缩略图/列表、单页/连续滚动、缩略图宽度、首批加载量和选中记忆。

### 统计与图表

- 统计分析、病案统计、图片访问审计和接口响应分析统一迁移到 ECharts。
- 增加统一图表主题、加载状态、空状态和响应式处理。
- 统计分析使用环形图展示类型分布，并用双轴组合图对比扫描页数和记录数。
- 病案统计使用柱状图展示每日新增、折线图展示累计记录，并支持长时间范围缩放。

### 系统界面

- 管理端重构为现代 SaaS 布局。
- 页面标题统一为英文标题、中文标题和说明三行结构。
- 页面标题可切换“页面同级”或“卡片”容器。
- 全局圆角可在设置中调整，业务卡片和常用控件同步变化。
- 系统设置改为更紧凑的分区布局，只保留已经接入实际功能的设置。
- 删除独立档案搜索页面、哀悼模式设置和侧边栏重复描述。

### 运维与文档

- 新增 `/status` 服务状态页，展示当前状态、近 90 天可用率和异常区间。
- 系统监控增加 PostgreSQL、HikariCP、表空间、锁等待、长事务和数据质量结果。
- 数据质量检查默认不自动执行，由管理员手动触发。
- 增加同域 VitePress 用户手册、内部文档和受权限保护的 Springdoc API 文档。

## 重要修复

- 修复路由切换时白屏、旧页面残影和档案袋样式残留。
- 修复同一次请求失败同时出现两次错误提示。
- 修复 Flyway 已执行迁移校验和不一致导致后端无法启动。
- 修复帮助菜单和档案装箱指标图标无法显示或遮挡文字。
- 修复弹窗打开和关闭时页面因滚动条补偿而左右抖动。
- 修复病案明细分页数量与卡片网格列数不一致。

## 使用前注意

### PDF 导出依赖 CORS

PDF 由浏览器直接读取图片生成。图片服务没有允许管理端来源时，会出现跨域错误，必须由运维人员修复 Nginx 或图片服务响应头。

### 状态页不是独立监控服务

`/status` 与主后端同进程运行。后端完全停止时状态页也无法打开；服务恢复后会根据心跳历史补录停机区间。

### 当前仍是开发快照

- 暂无稳定产品版本号和 GitHub Release。
- 正式部署不依赖 Docker。
- GitHub Actions 可能因账户额度不足而在执行步骤前失败。
- 页面是否支持某项导出、编辑或删除操作，应以当前账号实际显示的按钮和权限为准。
