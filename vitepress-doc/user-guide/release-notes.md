# 更新说明

> 本页对应 `main` 当前产品版本 **v0.6.3**。完整提交历史见 [Git 更新记录](./changelog)，数据库和回滚条件见内部文档中的发布基线。

## 0.6.3 重点变化

### Windows 一键管理与 Nginx

- Windows 离线发布包包含 Nginx 配置和管理脚本；
- 提供启动、停止、重载和状态检查能力；
- 修复脚本编码和中文环境兼容问题；
- 发布包通过 `manifest.json` 和 `SHA256SUMS` 描述版本与文件校验。

### Nginx 文件浏览

- 新增“业务 → Nginx 文件浏览”；
- 支持 `default`、`BA01`、`BA02`、`BA03` 四个图片节点；
- 兼容 JSON 和 HTML autoindex；
- 支持目录浏览、图片预览、文件打开和下载；
- 后端限制服务器和路径，防止路径穿越和任意 URL 访问。

### OSS 迁移与文件浏览

- 按“上架号前 4 位 / 上架号-病案号”组织 OSS 目录；
- 从 Nginx 获取原图并上传 OSS；
- 上架号为空的病案进入等待补齐状态；
- 支持分阶段任务、失败重试、校验和进度展示；
- 新增只读 OSS 文件资源管理器；
- 签名 URL 生成前会重新校验受管路径。

### 患者管理

- 支持编辑患者信息；
- 支持 CSV、XLSX、XLS 导入；
- 支持条件导出；
- 增加身份证为空、疑似同一患者、年度病案和科室分布统计；
- 导入流程处理重复、编码、模板和错误明细；
- 大量导出避免一次性把全部数据加载到内存。

### 注册与审核

- 登录页开放自助注册；
- 注册后账号进入 `pending` 状态；
- 管理员在用户管理中批准并分配角色，或填写原因拒绝；
- 密码规则统一为 6～64 位；
- 修复匿名注册被登录/权限拦截器阻止的问题；
- 保留注册限流和安全审计。

### 影像档案袋导出

- ZIP 和 PDF 使用独立权限：`record:download`、`record:pdf:export`；
- 大病案自动转为后台生成任务；
- 按钮显示排队、生成、成功、失败、取消和过期状态；
- 支持取消、重新下载、临时文件清理和断点下载；
- 每次 PDF 导出都使用当前选中的图片，不复用上一次结果；
- 同一病案中的 OSS 与非 OSS 图片可以混合读取和降级。

## 使用前注意

### 前后端版本必须一致

注册、权限、导出任务和文件浏览都同时依赖前后端。升级后若仍出现旧行为，检查：

- 页面显示版本；
- `/actuator/info` 的后端版本；
- Nginx 是否仍缓存旧静态文件；
- API 是否代理到当前 JAR；
- 浏览器是否加载旧 Service Worker 或缓存资源。

### 导出依赖后端网络

图片在浏览器中可以预览，不代表后端一定可以访问。ZIP/PDF 失败时重点检查后端到 Nginx、NAS、HTTP 和 OSS 的网络、凭据和路径。

### 临时文件会过期

后台导出文件默认保留一段时间，过期后需要重新生成。不要把任务下载地址作为长期链接保存。

### 文件浏览器是只读排障工具

OSS/Nginx 文件浏览器不替代影像档案袋，不提供上传、删除、移动和重命名，也不应向无业务需要的账号开放。

### 状态页不是独立监控系统

`/status` 与主后端同进程运行。后端完全停止时状态页也无法打开；服务恢复后会根据历史心跳补录停机区间。

## 已知边界

- 正式环境以 Windows Server 原生部署为主，不依赖 Docker；
- `mr_scan` 为数千万级大表，大范围修复和迁移必须分批执行；
- Token 撤销黑名单依赖后端进程内存，重启后仍需依赖密码版本和 Token 有效期；
- 菜单隐藏不等于撤销权限；
- 开发者模式只能用于受控联调，真实患者数据环境必须关闭；
- 尚未合并的 PR 和 Issue 不属于当前版本能力。
