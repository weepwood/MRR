# 统计分析

MRR 的统计模块用于观察病案扫描规模、页数、记录数、时间趋势和明细数据。图表统一使用 ECharts，并复用主题、加载状态、空状态和响应式处理。

## 统计分析

进入“业务 → 统计分析”。当前页面重点展示：

- 扫描记录、扫描页数等汇总指标。
- 扫描页数与扫描记录数双轴趋势图。
- 近期记录、近期页数和日均页数摘要。
- 全部日期汇总数据，默认缩放到最近 90 日。

旧版“病案类型分布”图表已经删除，当前页面不再展示环形类型分布。

### 扫描趋势

双轴组合图同时展示：

- 柱状系列：扫描页数。
- 折线系列：扫描记录数。

两者单位不同，应分别阅读左右坐标轴。默认窗口显示最近 90 日，在图表区域使用鼠标滚轮可以放大或缩小时间范围；缩放只改变可视范围，不会删除后端返回的历史汇总数据。

## 统计明细

进入“业务 → 统计明细”。页面用于从汇总结果下钻到具体病案，常见信息包括：

- 患者姓名。
- 住院科室。
- 出院日期。
- 病案号。
- 上架号。
- 扫描页数。

点击目标病案可进入影像档案袋。编号按数据库原始格式显示和传递，不应为了统一长度手工补零。

卡片分页会根据容器宽度和实际列数调整请求数量，减少非末页出现残缺行。切换窗口宽度后，页面可能重新计算单页数量并刷新数据。

## 病案统计

进入“业务 → 病案统计”。趋势图使用：

- 柱状系列：每日新增记录。
- 折线系列：累计记录。

页面还可展示区间累计、日均记录、单日峰值和类型筛选。数据区间较长时，图表会启用内部缩放能力。

## 图表交互

统一图表组件支持：

- 浏览器尺寸变化后自动重绘。
- 页面重新激活后恢复尺寸。
- 明暗主题适配。
- 加载状态和无数据状态。
- 图例、提示框和按需启用的数据缩放。

鼠标悬停提示框只用于查看当前点位，不应把单个异常点直接解释为系统故障。

## 数据核对

统计结果异常时按以下顺序检查：

1. 确认日期、类型、科室等筛选条件。
2. 确认当前指标单位是记录数还是页数。
3. 检查趋势图缩放范围，避免只查看局部日期。
4. 打开统计明细核对具体病案。
5. 在记录管理中复核源记录。
6. 管理员检查 `mr_archive` 与业务表的 `archive_id` 关联情况。
7. 运行数据质量检查并核对图片文件或 OSS 迁移状态。

## 功能边界

当前统计页面不提供：

- 任意自定义维度拖拽分析。
- 保存个人报表模板。
- 定时邮件发送报表。
- 所有页面统一导出 Excel、CSV 或完整图文 PDF。

是否支持导出应以当前页面实际显示的按钮为准。
