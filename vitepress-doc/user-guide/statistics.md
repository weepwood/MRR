# 统计分析

## 统计概览

首页仪表盘展示关键数据：

- 总患者数
- 总扫描次数
- 今日新增
- 设备分布
- 月度趋势

## 统计模块

### 1. 每日统计

按日期维度的统计：

| 指标 | 说明 |
|------|------|
| 日扫描量 | 每日的扫描记录数量 |
| 日新增患者 | 每日新增的患者数量 |
| 日活跃用户 | 每日操作系统的用户数 |
| 对比分析 | 环比、同比变化 |

支持选择日期范围查看趋势图。

### 2. 设备类型统计

按设备类型（CT / MRI / X-ray / 超声）统计：

- 各类型占比（饼图）
- 各类型数量趋势（折线图）
- 各类型平均扫描时长（柱状图）

### 3. 科室统计

- 各科室扫描数量
- 各科室患者来源
- 趋势对比

### 4. 趋势分析

- **日趋势**: 过去 30 天的变化趋势
- **月趋势**: 过去 12 个月的变化趋势
- **年趋势**: 历年对比分析

## 图表类型

系统支持以下图表展示：

- 折线图（趋势分析）
- 柱状图（对比分析）
- 饼图（占比分析）
- 环形图（占比分析）
- 堆叠图（复合分析）

## 导出报表

### 导出格式

- Excel（.xlsx）
- PDF
- CSV

### 导出内容

- 原始数据表
- 统计图表（截图）
- 完整报表（数据+图表）

## 自定义统计

### 筛选条件

- 时间范围
- 设备类型
- 科室/部门
- 患者年龄段
- 性别

### 保存报表

- 保存常用筛选条件
- 支持报表命名
- 支持定时发送报表（邮件）
