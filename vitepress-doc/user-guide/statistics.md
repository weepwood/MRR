# 统计分析

MRR 的统计模块用于观察病案扫描规模、类型分布、时间趋势和明细记录。当前业务图表统一使用 ECharts，并复用相同的主题、加载状态、空状态和响应式逻辑。

## 统计分析

进入“业务 → 统计分析”。页面重点展示：

- 病案或扫描汇总指标
- 病案类型分布环形图
- 近 10 日扫描趋势
- 扫描页数与扫描记录数双轴对比
- 近期记录、近期页数和日均页数摘要

### 类型分布

环形图用于比较不同病案类型的数量和占比。筛选条件变化后，图表与摘要会同步刷新。

### 扫描趋势

双轴组合图同时展示：

- 柱状系列：扫描页数
- 折线系列：扫描记录数

两者量纲不同，应分别阅读左右坐标轴，不能直接把柱高和折线高度当作同一单位比较。

## 统计明细

进入“业务 → 统计明细”。该页面用于从汇总结果下钻到具体病案，支持卡片或列表展示。

常见信息：

- 患者姓名
- 科室
- 出院日期
- 病案号
- 上架号
- 扫描页数

点击目标病案可进入影像档案袋。卡片分页会根据容器宽度和实际列数调整请求数量，减少非末页残缺行。

## 病案统计

进入“业务 → 病案统计”。当前趋势图使用：

- 柱状系列：每日新增记录
- 折线系列：累计记录

页面还提供：

- 区间累计
- 日均记录
- 单日峰值
- 类型筛选

数据区间超过 16 天时，图表会启用内部缩放能力，便于查看较长时间范围。

## 图表交互

统一图表组件支持：

- 浏览器尺寸变化后自动重绘
- 页面 KeepAlive 激活后恢复尺寸
- 明暗主题变量适配
- 加载状态和无数据状态
- 图例、提示框和数据缩放（按图表需要启用）

切换页面后看到旧页面图表残影属于异常；当前版本已移除主内容区路由过渡叠加，正常情况下页面会直接替换。

## 数据核对

统计结果异常时按以下顺序检查：

1. 确认日期、类型、科室等筛选条件。
2. 确认图表单位是记录数还是页数。
3. 打开统计明细核对具体病案。
4. 在记录管理中复核源记录。
5. 管理员运行手动数据质量检查。
6. 检查 OSS 迁移校验和图片文件是否一致。

## 功能边界

当前统计页面不承诺以下功能：

- 任意自定义维度拖拽分析
- 保存个人报表模板
- 定时邮件发送报表
- 所有页面均导出 Excel、CSV 或完整图文 PDF

是否支持导出应以当前页面实际显示的按钮为准。
