# 存储与文件浏览

MRR 提供两个只读文件浏览入口，用于检查图片存储结构、迁移结果和文件可访问性：

- “业务 → OSS 文件浏览”；
- “业务 → Nginx 文件浏览”。

两个页面默认需要 `record:read` 权限。文件浏览功能用于核对和排障，不替代影像档案袋的业务访问审计，也不提供删除、移动、重命名或上传操作。

## OSS 文件浏览

OSS 文件浏览器以类似 Windows 文件资源管理器的方式展示受管 Bucket 中的目录和对象。

### 支持操作

- 进入前缀目录；
- 返回上级目录；
- 按名称和类型查看对象；
- 预览支持的图片；
- 打开或下载文件；
- 查看对象大小、更新时间和路径；
- 复制受控对象路径用于排障。

### 安全边界

- 浏览范围只允许已配置的受管 Bucket 和前缀；
- 后端在生成签名 URL 前再次校验对象路径；
- 不能通过 `..`、编码变体或伪造前缀跳出受管路径；
- 签名 URL 有有效期，不应作为永久地址保存；
- 页面缓存不能绕过路径校验。

### 常见用途

- 核对某个上架号是否已经迁移；
- 检查 OSS 目录是否符合迁移规则；
- 比较数据库 `oss_url` 与实际对象；
- 确认失败任务是否已经写入部分对象；
- 抽样验证对象大小和图片可读性。

## Nginx 文件浏览

Nginx 文件浏览器用于访问以下图片服务器配置：

| 节点 | 环境变量 |
| --- | --- |
| `default` | `IMAGE_SERVER_URL_DEFAULT` |
| `BA01` | `IMAGE_SERVER_URL_BA01` |
| `BA02` | `IMAGE_SERVER_URL_BA02` |
| `BA03` | `IMAGE_SERVER_URL_BA03` |

页面兼容 Nginx JSON autoindex 和普通 HTML autoindex。后端负责访问、解析和代理文件，浏览器不直接信任任意外部 URL。

### 支持操作

- 切换配置好的图片节点；
- 浏览目录和返回上级目录；
- 查看文件名、类型、大小和时间；
- 预览图片；
- 打开或下载文件；
- 通过后端代理读取文件，减少浏览器跨域限制。

### Nginx 建议配置

推荐为专用只读目录启用 JSON autoindex：

```nginx
location /ba-img-01/ {
    alias D:/medical-images/ba-img-01/;
    autoindex on;
    autoindex_format json;
    autoindex_localtime on;
}
```

不要把系统盘、配置目录、日志目录或用户目录暴露为 autoindex。图片目录应使用单独的只读 location。

### 路径保护

后端会拒绝：

- `..` 等路径穿越；
- 未配置的服务器节点；
- 非 HTTP/HTTPS 的任意协议；
- 超出受控基础 URL 的重定向或拼接路径；
- 伪造主机名、端口或绝对 URL。

## OSS 迁移目录规则

当前迁移路线为：

1. 从 Nginx 获取原图；
2. 使用上架号前 4 位进行分组；
3. 目录名称使用“上架号-病案号”；
4. 目录下保留图片文件名；
5. 上架号为空的病案进入等待补齐状态，不立即上传。

示意：

```text
medical-records/
└── 6666/
    └── 666666-00789124/
        ├── 0013.jpg
        └── 0014.jpg
```

实际前缀由 OSS 配置和迁移实现决定，排障时以迁移任务详情和对象浏览器显示为准。

## 文件浏览与影像档案袋的区别

| 功能 | 文件浏览器 | 影像档案袋 |
| --- | --- | --- |
| 主要目的 | 存储排障与迁移核对 | 业务调阅与导出 |
| 查询依据 | 目录/对象路径 | 病案号、上架号、身份证 |
| 患者信息 | 不展示或仅有限信息 | 展示脱敏病案信息 |
| 分类浏览 | 按文件结构 | 按病案类型和页序 |
| 下载权限 | `record:read` 下的只读文件操作 | ZIP 需要 `record:download` |
| PDF | 不支持 | 需要 `record:pdf:export` |
| 审计语义 | 运维/存储访问 | 病案业务访问 |

不要让普通业务人员使用文件浏览器代替影像档案袋。

## 常见问题

### 页面没有可选节点

检查对应 `IMAGE_SERVER_URL_*` 是否已配置并重启后端。空配置不会出现在可用节点列表中。

### Nginx 目录为空

检查基础 URL、alias/root、目录权限、autoindex 和 URL 末尾斜杠。使用浏览器或服务器本机测试 URL 时，也应确认响应来自目标 Nginx 实例。

### HTML autoindex 解析异常

优先改用 `autoindex_format json`。不同 Nginx 主题或第三方目录页面可能改变 HTML 结构，JSON 更稳定。

### OSS 文件可以浏览但影像档案袋仍回退本地

检查数据库记录是否存在正确的 OSS 地址、签名配置是否有效、对象路径是否在受管前缀中，以及当前图片来源设置。浏览器看到对象存在不代表业务记录已经完成关联。

### 文件打开后 403

签名 URL 可能已过期，刷新目录后重新打开。若持续失败，检查服务器时间、OSS AccessKey、Bucket 权限和 endpoint/region 配置。
